# DailyToolkit 0.8.1

文件集装箱新增快速装载窗口、快捷打包和独立配色。

## 更新内容

- 按 `Ctrl + Alt + P` 呼出或关闭快速窗口，可修改快捷键。文件逐项显示，支持拖入、选择和移除。
- “打包”打开独立的详细打包窗口；“快捷打包”使用预先设置的文件名、格式、压缩级别和保存位置。
- 功能设置、快速装载、详细打包各有独立配色和预览。预设点击即保存，自定义颜色保存后应用。
- 可在设置中添加资源管理器右键入口。Windows 11 位于“显示更多选项”，支持将所选文件和文件夹装入快速窗口。
- 增加文件集装箱功能开关。停用后关闭快捷呼出，已提交的任务继续执行。

Windows 11 第一层右键菜单暂不支持。资源管理器与软件权限不一致时，右键装载可能失败，可从窗口中选择文件。

## 下载与更新

| 文件 | 使用方式 |
| --- | --- |
| `DailyToolkit-0.8.1-win-x64-setup.exe` | 运行安装；已有安装版可直接升级 |
| `DailyToolkit-0.8.1-win-x64-portable.zip` | 解压后打开 `DailyToolkit.exe` |
| `SHA256SUMS.txt` | 核对下载文件的 SHA-256 |

已有版本可在“设置 → 关于”中检查更新，笔记、剪贴历史和个人设置会保留。无需另外安装 .NET 或压缩软件。
