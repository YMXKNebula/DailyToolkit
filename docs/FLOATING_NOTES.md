# 浮笺

浮笺是一张可以留在桌面上的文本笔记。主窗口关闭到托盘后，笔记和快捷键仍可使用。

## 显示、编辑和隐藏

| 操作 | 默认方式 |
| --- | --- |
| 显示或隐藏 | `Ctrl + Alt + N` |
| 切换已显示笔记的编辑状态 | `Ctrl + Alt + Shift + N` |
| 结束编辑 | 聚焦快捷键或 `Esc` |
| 移动 | 编辑时，在可移动模式下按住空白顶部拖动 |
| 隐藏 | 编辑时点击左下角按钮 |
| 调整大小 | 编辑时拖动右下角 |

两个快捷键可以分别更改、清空或恢复默认。聚焦快捷键只切换已经显示的笔记；要呼出隐藏的笔记，使用显示快捷键。

正文支持多行输入、中文输入法、双击选词、右键菜单、复制粘贴和撤销。可使用 `Ctrl + A/C/X/V/Z/Y`。中文输入法正在组合输入时，第一次 `Esc` 取消组合，再按一次结束编辑。

结束编辑后，笔记保持显示，并尝试返回此前使用的窗口。直接点击其他程序或使用 `Alt + Tab` 也可以结束编辑。

## 鼠标穿透与点击编辑

默认情况下，结束编辑后的所有鼠标操作都会到达笔记下方的程序。

如需点击笔记开始编辑，在“位置”中开启“点击浮笺聚焦”。开启后，左键点击正文、背景或顶部会进入编辑，右键、中键和滚轮仍穿透。这次左键只用于聚焦，不会同时拖动、选词或点击下方窗口。

编辑状态下显示边框、滚动条、隐藏按钮和缩放角；结束编辑后收起这些控件，不能直接拖动、缩放或滚动笔记。

## 位置和大小

- **固定**：笔记留在设定位置，编辑时仍可以使用右下角缩放。
- **可移动**：编辑时顶部中央显示横杠，按住空白顶部即可拖动，支持跨显示器移动。
- **宽高**：宽度范围 240–1200，高度范围 180–1400，填写整数。实际像素大小会随显示器缩放变化。
- **手动缩放**：“允许拖动右下角调整大小”默认开启，关闭后仍可在设置中填写宽高。
- **置顶**：选择笔记是否始终显示在其他窗口上方。

笔记完全离开可用屏幕时会回到主屏，也可以点击“重置位置”找回。

结束编辑后，正文区域上下会多显示已有内容，没有更多文字时留白。编辑时恢复原来的范围和滚动位置，文字不会被拉伸。

## 颜色和字体

外观设置旁有实时预览，宽窗口在右侧，窄窗口在上方。可以切换“聚焦效果预览”，查看编辑和非编辑状态。

| 设置 | 可以调整的内容 |
| --- | --- |
| 配色 | 纸白、暖黄、浅蓝、薄荷、淡粉、淡紫、沙色、石墨、夜蓝、墨绿十套预设 |
| 独立颜色 | 背景、文字、编辑边框；点击色块或自选颜色按钮选择 |
| 透明度 | 背景和文字分别调整 |
| 编辑时不透明 | 默认开启，可关闭“聚焦时完全不透明” |
| 字体 | 本机字体、10–72 字号、粗体和字体样式预设 |
| 圆角 | 调整背景四角的弧度 |

正文边框和外框使用同一颜色，边框与滚动条跟随背景透明度。结束编辑后边框消失，背景和文字使用各自设置的透明度。

编辑长笔记时，有文字被遮挡的上下边缘会逐渐变淡，提示还有内容可滚动查看；这是一种固定显示效果。短笔记和非编辑状态不使用渐隐。

## 保存、导出和恢复

输入停止约 400 毫秒后自动保存，隐藏和正常退出也会保存最后的编辑。保存失败时请使用“立即保存”重试，或“导出文本”保留副本。

点击“打开数据目录”可以查看笔记文件：

| 文件 | 内容 |
| --- | --- |
| `default.txt` | UTF-8 笔记正文 |
| `settings.json` | 快捷键、位置、大小和外观 |
| 对应的 `.bak` | 上次成功替换前的备份 |

数据目录为 `%LOCALAPPDATA%\DailyToolkit\Notes\`。更新或移动程序文件夹不会清空笔记；“恢复默认设置”也不会删除正文。

如果正文无法读取，请先退出软件，再检查正文和备份文件。设置损坏时会临时使用默认值，确认需要重设后可恢复全部默认设置。突然断电或强制结束可能丢失最后尚未保存的输入。

笔记只保存在本机，不联网同步，也不写入电脑信息报告。

## 无法返回之前的窗口时

Windows 有时会拒绝切换前台窗口。遇到提示后，直接点击要继续使用的程序即可。浮笺不会反复抢回焦点。
