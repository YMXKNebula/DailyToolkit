# 浮笺

浮笺是独立的桌面文本笔记。主窗口关闭到托盘后，笔记仍可显示、编辑和使用快捷键。

| 操作 | 默认方式 | 结果 |
| --- | --- | --- |
| 显示 / 隐藏 | Ctrl + Alt + N | 隐藏时显示并聚焦，显示时保存并隐藏 |
| 再次聚焦 | Ctrl + Alt + Shift + N | 只聚焦可见笔记，保留选区与编辑位置 |
| 取消聚焦 | Esc 或双击浮笺任意位置 | 保持显示，尝试恢复此前窗口；双击行为可关闭 |
| 鼠标再次聚焦 | 点击浮笺任意位置 | 默认开启；关闭后使用快捷键或设置页的再次聚焦按钮 |
| 移动 | 可移动模式下，按住顶部区域并拖动 | 移过系统拖动距离即开始，无需长按等待 |
| 调整尺寸 | 拖动右下角 | 固定模式也可以调整尺寸 |

正文保留多行输入、中文输入法、滚动、上下文菜单以及 Ctrl+A/C/X/V/Z/Y。关闭“双击任意位置取消聚焦”后，正文双击可选词。输入法正在组合输入时，第一次 Esc 用于正常取消组合，不退出编辑。固定与可移动只控制拖动，始终置顶只控制窗口叠放，两者都不等于持续聚焦。

## 设置

左侧“浮笺”页提供快捷键、位置、鼠标与聚焦、背景外观、字体外观及数据管理。位置使用与屏幕局部放大一致的“固定／可移动”单选项，快捷键行右侧星标用于收藏。红绿开关控制工具启停，收藏和排序使用现有导航。

“双击任意位置取消聚焦”和“点击浮笺再次聚焦”分别保存、默认开启。关闭点击开关时，未聚焦的浮笺不会因为点击正文、顶部或边框而获得输入焦点；快捷键和设置页的再次聚焦按钮仍可使用。已经聚焦时仍可正常编辑。Esc 不受这两个开关影响。

两个快捷键与屏幕局部放大的快捷键相互检查；其它程序占用快捷键时会显示注册失败提示。可以更换或清空组合键，也可以恢复默认快捷键。再次启用只恢复注册，不自动显示窗口。

背景有浅色、黄色、浅蓝、浅绿、深灰和半透明黑六个预设；字体另有正文、大字、白色和等宽预设。修改背景不会重置字体，修改字体不会改变背景。颜色输入使用 `#RRGGBB`，输入框后的色块显示当前颜色，文字和背景透明度分别控制，整体窗口不变淡。字号范围是 10–72。字体仅从本机已有字体列表中选择，缺失时使用系统字体回退。

外观预览与设置滚动区分开，宽窗口显示在右侧，窄窗口显示在上方。滚动到背景或字体设置时，预览仍可见，调整会即时显示。

位置在当前可用屏幕完全不可见时自动恢复到主屏。“重置位置”也可找回笔记。跨屏移动使用普通 Windows/WPF 窗口规则，不使用放大框的镜像接力。

## 数据与恢复

数据目录为 `%LOCALAPPDATA%\DailyToolkit\Notes\`，与便携版本目录无关：

- `default.txt`：当前单条笔记的 UTF-8 正文。
- `settings.json`：显示方式、快捷键、鼠标聚焦开关、位置、尺寸和外观。
- 对应 `.bak`：上次成功替换之前的文件，用于必要时人工恢复。

输入停止约 400 毫秒后异步保存。隐藏和正常退出也会保存，保存失败时保留内存正文并给出提示，不销毁含有未保存内容的窗口。请使用“立即保存”重试或“导出文本”保存副本；不要在失败提示下强制结束程序。突然断电或强制结束仍可能丢失最后尚未保存的输入。

恢复默认设置不会清空正文。损坏或无法读取的正文不会自动当作空白覆盖；请打开数据目录，退出程序后检查正文和备份。损坏设置临时使用默认值，恢复全部默认设置后才允许重新保存。数据不联网同步，也不包含在电脑信息报告中。

## 焦点限制

浮笺在每次唤出、再次聚焦以及用户点击重新激活时，更新此前有效的前台窗口。Alt+Tab 或点击其它程序仅使笔记自然失焦，不会自动恢复旧目标或抢回焦点。

Windows 可以拒绝前台激活，即使目标仍有效。此时浮笺清除自己的输入焦点并提示，用户直接点击目标窗口即可。程序不轮询抢占，也不模拟全局点击绕过限制。相关系统规则见 [Microsoft 的 SetForegroundWindow 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow)。

## 手动验收

自动检查覆盖本机临时数据、损坏与写入失败、原生热键、测试窗口的焦点、选区、透明度和生命周期。以下仍应在具体使用环境人工检查：

1. 在浏览器输入框输入文字，用快捷键 A 呼出浮笺并编辑；按 Esc，应回到浏览器输入框且浮笺保持显示。换用文本编辑器重复。用快捷键 B 再编辑，应保留原选区和光标位置。
2. 点击另一个程序或按 Alt+Tab；浮笺不得抢回焦点。点击笔记正文应自然重新编辑，按 Esc 应返回这次点击前的程序。关闭此前程序，再按 Esc，应显示提示并停止接收输入。
3. 使用中文拼音输入法保持候选组合，按一次 Esc 应取消组合，继续输入应正常。无组合时再次 Esc 应取消聚焦。检查选词、右键菜单、复制剪切粘贴、全选、撤销和重做。
4. 开启双击开关，左键双击正文、顶部或边框均应取消聚焦，右键双击顶部也应取消聚焦。关闭开关后，正文双击应选词，顶部双击不得取消聚焦或误拖。关闭点击开关，未聚焦时点击浮笺应保持当前程序的输入焦点；快捷键 B 仍应可聚焦。
5. 固定模式禁止拖动但仍可编辑、缩放尺寸。可移动模式无需等待即可从顶部拖动；轻微手抖未超过系统拖动距离时仍视为点击。从左屏到右屏以及上下排列屏幕拖动，尤其检查混合 DPI 下手柄与指针保持连续；不改变真实显示器排列来代替测试。
6. 在副屏放置浮笺，然后人工拔掉该屏或改变排列，应找回窗口；也可使用重置位置。显示器排列和拔插操作不由自动测试修改。
7. 更换六种背景及字体预设，修改独立透明度、颜色与字号；滚动到不同设置时预览应保持可见，文字色块应随有效颜色立即更新。窄窗口检查预览在上方。隐藏、再次显示、完全退出后重开，都应保留正文及设置。主窗口留在托盘期间笔记应可编辑。
8. 同时使用屏幕放大的热键、固定/移动模式、滚轮和 16× 缩放，检查跨屏、画质、主题、收藏及工具启停。

涉及浏览器、输入法、真实拔插及各种上下排列的项目不因自动测试通过而视为全部完成实机验收。
