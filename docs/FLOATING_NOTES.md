# 浮笺

桌面文本笔记，输入后自动保存，主窗口留在托盘时仍可使用。

## 操作

| 操作 | 方式 |
| --- | --- |
| 显示 / 隐藏 | `Ctrl + Alt + N` |
| 切换已显示笔记的编辑状态 | `Ctrl + Alt + Shift + N` |
| 结束编辑 | `Esc` |
| 移动 | 可移动模式下，编辑时拖动空白顶部 |
| 调整大小 / 隐藏 | 编辑时拖动右下角 / 点击左下角 |

两个快捷键可分别修改或清空。中文输入法组合输入时，第一次 Esc 取消组合，再按一次结束编辑。

结束编辑后鼠标穿透。开启“点击浮笺聚焦”后，可用左键进入编辑；右键、中键和滚轮仍穿透。点击其他程序也会结束编辑。

## 外观与位置

支持固定或可移动、置顶、整数宽高、圆角、字体和透明度。宽度 240–1200，高度 180–1400；“重置位置”可找回屏幕外的笔记。

配色预设点击即保存。自定义背景、文字和聚焦边框只改变预览，点击“立即保存”后应用。可切换聚焦预览，调整背景与文字透明度、字号和粗体。

编辑长笔记时，上下边缘渐隐提示还有内容；结束编辑后收起边框和操作按钮。

## 保存与恢复

停止输入约 400 毫秒后自动保存，隐藏或正常退出也会保存。失败时请“立即保存”重试，或“导出文本”后再退出。

数据位于 `%LOCALAPPDATA%\DailyToolkit\Notes\`：正文 `default.txt`，设置 `settings.json`，各有 `.bak` 备份。更新、移动程序或恢复默认设置不删除正文。

读取失败时请先保留原文件和备份。突然断电或强制结束可能丢失尚未保存的输入。笔记仅在本机保存，不联网同步。

无法返回之前窗口时，直接点击要使用的程序即可。
