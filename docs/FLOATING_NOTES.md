# 浮笺

浮笺是独立的桌面文本笔记。主窗口关闭到托盘后，笔记仍可显示、编辑和使用快捷键。

| 操作 | 默认方式 | 结果 |
| --- | --- | --- |
| 显示 / 隐藏 | Ctrl + Alt + N | 隐藏时显示并聚焦，显示时保存并隐藏 |
| 聚焦 | Ctrl + Alt + Shift + N | 切换已显示笔记的编辑状态，保留选区与光标位置 |
| 取消聚焦 | 聚焦快捷键或 Esc | 保持显示，尝试恢复此前窗口 |
| 移动 | 聚焦且可移动时按住空白顶部并拖动 | 移过系统拖动距离即开始 |
| 隐藏按钮 | 聚焦时的左下角 | 保存并隐藏 |
| 调整尺寸 | 聚焦时的右下角 | 固定模式也可调整，可在尺寸旁关闭 |

默认只通过快捷键开始编辑。失焦时鼠标操作穿透到下方程序。位置设置中的“点击浮笺聚焦”开启后，只接收左键点击正文、背景或顶部来聚焦；这次点击不会同时拖动、选词或传给下方程序，右键、中键和滚轮仍穿透。关闭后，所有鼠标操作穿透。聚焦后，正文双击可以选词，右键可打开文本菜单。正文支持多行输入、中文输入法、滚动以及 Ctrl+A/C/X/V/Z/Y。输入法正在组合输入时，第一次 Esc 正常取消组合，不退出编辑。

固定与可移动控制聚焦窗口是否能拖动，始终置顶控制叠放。聚焦时，可移动模式在顶部中央显示圆润横杠；固定模式没有移动提示，但仍可使用缩放角。隐藏和缩放控件只显示图形标记，没有底色或外边框，原有可点击和拖动区域保留。失焦时隐藏正文边框、滚动条、隐藏按钮、缩放角和移动提示，停止拖动、缩放、滚动、选词和文本菜单。

失焦后，正文显示区域的上下留边与左右相同。滚动过的内容可在上下多显示，文字位置、字号、行距和换行宽度保持原样；没有更多内容时留白，聚焦后恢复原来的编辑范围。窗口尺寸保持原设置。

聚焦时，有正文被遮挡的顶部或底部会静态渐隐：顶部向上变淡，底部向下变淡。没有遮挡的一端保持完整显示，短笔记不加渐隐；这不是动画，也不改变背景、边框和滚动条。失焦后移除渐隐。外观旁的预览使用相同效果。

## 设置

工具配置标题左侧的星标用于收藏；左下角收藏夹入口保留原位置。快捷键可以分别更换或清空，也可恢复默认；与屏幕局部放大或其它程序冲突时会显示提示。聚焦快捷键不会显示隐藏中的笔记，重新启用工具也不会自动显示。

宽度范围 240–1200、高度范围 180–1400，单位为 DIP，输入与保存均使用整数。旧版小数尺寸自动四舍五入。尺寸旁的“允许拖动右下角调整大小”默认开启，关闭后仍可在设置中填写宽高。

外观提供纸白、暖黄、浅蓝、薄荷、淡粉、淡紫、沙色、石墨、夜蓝和墨绿十套配色，同时设置背景、文字及聚焦边框颜色。每套文字与背景保持明显区分，应用配色不改正文、字体样式或尺寸。颜色可点击色块、调色板或自选颜色按钮，在系统颜色对话框中选择。

背景与文字透明度分别设置。聚焦时默认完全不透明，可关闭“聚焦时完全不透明”来使用设置值；取消聚焦后恢复设置值，边框消失。正文边框与外框使用同一颜色及背景透明度，滚动条也跟随背景透明度。边框颜色可以单独选择，也随配色预设更新。隐藏滚动条时，文字不会挤占原来的滚动条位置。

字体从本机字体列表选择，字号范围 10–72，支持粗体；字体样式预设保留当前配色，恢复默认字体则还原字体全部设置。背景圆角可调整。背景、字体、聚焦设置及预览在同一外观区域；宽窗口预览在右侧，窄窗口在上方，滚动设置时保持可见。预览的“聚焦效果预览”只切换示例状态，不影响实际笔记。

位置完全离开可用屏幕时，窗口自动回到主屏。“重置位置”也可找回笔记。跨屏移动按显示器 DPI 换算拖动点，不使用放大框的镜像接力。

## 数据与恢复

数据目录为 %LOCALAPPDATA%/DailyToolkit/Notes/，与便携版本目录无关：

- default.txt：当前笔记的 UTF-8 正文。
- settings.json：快捷键、位置、整数尺寸和外观设置。
- 对应 .bak：上次成功替换前的文件。

输入停止约 400 毫秒后异步保存，隐藏和正常退出也会保存。失败时保留内存正文并提示，可用“立即保存”重试或“导出文本”保存副本。突然断电或强制结束可能丢失最后尚未保存的输入。

恢复默认设置不会清空正文。损坏或无法读取的正文不会自动当作空白覆盖；请退出程序后检查正文及备份。损坏设置临时使用默认值，恢复全部默认设置后才允许重新保存。数据不联网同步，也不包含在电脑信息报告中。

## 焦点限制与检查

每次唤出、通过快捷键或开启的鼠标选项进入聚焦，都会更新此前有效的前台窗口。Alt+Tab 或点击其它程序使笔记自然失焦，不会恢复旧目标或抢回焦点。Windows 可以拒绝切换，即使窗口仍有效；程序只尝试一次并给出提示，不轮询抢占。系统规则见 [Microsoft 的 SetForegroundWindow 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow)。

自动检查使用隔离的笔记文件和测试窗口，覆盖保存、原生快捷键、鼠标不聚焦、选词、透明度、边框、整数缩放及跨屏移动。实际使用时还应检查：

1. 在浏览器或编辑器中呼出浮笺，连续按聚焦快捷键应在编辑与失焦之间切换；选区保留，隐藏中的笔记不应被该键显示。
2. 关闭点击聚焦时，失焦的所有鼠标操作应到达下方程序；开启后，只有左键聚焦浮笺，右键、中键和滚轮仍到达下方程序。取消聚焦后返回此前程序。聚焦后双击正文应选词，失焦不能拖动或缩放浮笺。
3. 使用中文输入法保持候选组合，第一次 Esc 取消组合；无组合时 Esc 取消聚焦。检查右键菜单、复制剪切粘贴与撤销。
4. 在混合 DPI 或上下排列屏幕间拖动，拖动点应跟随指针；改变显示器布局或拔掉副屏后应找回窗口。人工拔插不由自动检查代替。
5. 切换配色与独立颜色，检查预览和实际笔记的正文边框、滚动条透明度及失焦后的隐藏状态。聚焦时，固定和可移动模式都能缩放；关闭手动缩放后隐藏缩放角，保存后重开应保留整数尺寸和设置。长正文的上下遮挡边缘应渐隐，短正文和失焦正文不应渐隐。
6. 同时检查屏幕放大的快捷键、固定/移动、滚轮、画质，以及主题、收藏和工具启停。
