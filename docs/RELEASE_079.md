# DailyToolkit 0.7.9

Windows 桌面工具集，提供屏幕局部放大、浮笺和电脑信息查看。

## 功能和设置

- **屏幕局部放大**：1.00–16.00×，可选性能、清晰、质量、像素画质。快捷键、按住或切换、滚轮调节、尺寸、宽高比、位置、边框颜色和帧率上限均可设置，支持跨屏移动。
- **浮笺**：随时显示、编辑或隐藏笔记，自动保存。可设置快捷键、固定或可移动、整数宽高、手动缩放、点击聚焦、十套配色、独立颜色与透明度、字体、圆角和置顶。
- **主题与收藏**：十二套主题预设，自定义配色、动画速度和工具排序；点亮星标把工具加入收藏夹。
- **后台运行**：可设置托盘运行、开机自启、管理员启动和静默启动。
- **电脑详情**：查看硬件、网络、电源和软件安装记录，支持搜索、复制摘要和导出报告。

## 更新内容

- “关于”页增加“检查更新”：安装版下载安装包后自动升级并重新打开，便携版下载新版 ZIP，可选择保存位置。
- 提供安装版，支持安装、卸载和运行新版安装包升级；安装时可迁移已有开机自启。
- 浮笺的隐藏按钮和缩放角去掉底色，仅显示圆润的图形标记。
- 修复放大框开启后可能被误关闭，以及关闭时可能出现异常的问题。

## 下载和使用

| 下载文件 | 使用方式 |
| --- | --- |
| `DailyToolkit-0.7.9-win-x64-setup.exe` | 运行安装，安装后从开始菜单打开；可在 Windows 中卸载 |
| `DailyToolkit-0.7.9-win-x64-portable.zip` | 解压后运行 `DailyToolkit.exe` |
| `SHA256SUMS.txt` | 核对下载文件的 SHA-256 摘要 |

无需另外安装 .NET。默认 `Ctrl + Shift + F8` 开启放大，`Ctrl + Alt + N` 显示或隐藏浮笺。

如果之前下载的 0.7.9 没有更新按钮，请先手动安装或替换这次下载包。笔记、设置和备份保存在用户数据目录，升级和卸载会保留。
