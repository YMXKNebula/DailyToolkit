## 2026-10-10 安装包

同一 Release 现在提供两种包，软件内仍显示 0.7.9，原有功能和界面保持不变。

- **安装版**：`DailyToolkit-0.7.9-win-x64-setup.exe`。当前用户安装，创建开始菜单快捷方式；运行新版安装包升级，在 Windows 中卸载。
- **便携版**：`DailyToolkit-0.7.9-win-x64-portable.zip`。解压运行，退出后替换文件升级。
- **校验文件**：`SHA256SUMS.txt`，包含两个包的 SHA-256 摘要。

升级和卸载先请求程序正常退出，无法保存笔记或释放文件时停止操作。笔记、设置和备份保留。安装向导可以迁移已有自启，管理员任务需要 Windows 授权；卸载只清理仍指向安装目录的自启入口，保留便携版入口和安装目录中自行添加的文件。

没有加入软件内自动检查或下载更新。安装与便携迁移步骤见[安装说明](INSTALLATION.md)，检查范围见[安装包验证记录](INSTALLER_CHECKS_079.md)。
