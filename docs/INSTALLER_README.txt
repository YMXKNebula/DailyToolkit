DailyToolkit 0.7.9

安装、升级和卸载
安装版包含 .NET 运行环境，已在 Windows 11 x64 上测试。安装器的最低系统检查为 Windows 10 2004，Windows 10 的实际功能尚未验证。
默认安装到 %LOCALAPPDATA%\Programs\DailyToolkit，当前用户安装不需要管理员权限。
“关于”页点击“检查更新”，发现新版后点击“更新”，软件会下载、校验并自动安装到原目录，完成后重新打开。
也可以手动运行新版安装包升级。不会在后台定期检查更新；重新上传同一版号的包不会被识别为更高版本。
安装程序会要求 DailyToolkit 正常退出；笔记未能保存或程序未退出时停止安装，不强行结束进程。
开始菜单提供快捷方式，桌面快捷方式可以在安装时选择。

从便携版迁移
安装版和便携版使用同一份笔记和设置，同一用户只运行一个实例。
有开机自启时，可以在安装时选择将自启入口改到安装目录。管理员自启迁移需要一次 Windows 授权。
取消授权时保留原自启入口；请在安装版设置中关闭并重新启用自启，旧便携目录暂时保留。
升级已经安装的版本不会改变程序路径，也不需要重新授权自启。

卸载
在 Windows“已安装的应用”中找到 DailyToolkit，或运行安装目录里的 unins 开头的卸载程序。
卸载会正常退出安装版，清理程序文件、快捷方式，以及仍指向本安装目录的自启入口。
指向便携版的自启入口保留，正在运行的便携版也不会被卸载程序关闭。
卸载保留 %LOCALAPPDATA%\DailyToolkit 中的笔记、设置和 .bak 备份。
重新安装会继续使用这些数据。如果要彻底删除数据，请先备份笔记，再自行删除这个用户数据目录。
