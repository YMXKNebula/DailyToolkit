DailyToolkit 0.7.9

Windows 桌面工具集：屏幕局部放大、浮笺和电脑信息查看。

安装
运行安装包，按向导选择安装位置和快捷方式。默认安装到 %LOCALAPPDATA%\Programs\DailyToolkit，只为当前用户安装，默认不需要管理员权限。
安装后从开始菜单打开，桌面快捷方式可以在安装时选择。下载包包含运行环境，无需另外安装 .NET。
目前提供 Windows x64 版本，已在 Windows 11 x64 上测试，Windows 10 完整兼容性尚未验证。

常用功能
屏幕局部放大：Ctrl + Shift + F8 开启或关闭。可修改快捷键、倍率、画质、宽高比、位置、滚轮调节和边框颜色。
浮笺：Ctrl + Alt + N 显示或隐藏，Ctrl + Alt + Shift + N 切换编辑状态。可设置位置、大小、十套配色、背景和文字透明度、字体、圆角、置顶和点击聚焦。
设置：选择主题、自定义配色、调整或关闭动画，设置托盘运行、开机自启、管理员启动和静默启动。
电脑详情：查看硬件、网络、电源和软件安装记录，支持搜索、复制摘要和导出报告。

更新
在“设置 → 关于”点击“检查更新”，发现新版后点击“更新”。下载校验完成后自动安装到原目录，完成后重新打开软件。
也可以手动运行新版安装包。更新前会保存笔记并正常退出；如保存失败，请先重试保存或导出文本。
检查更新由按钮触发，不在后台定期联网。

从便携版迁移
安装版会读取已有笔记和设置。安装时可选择把开机自启入口改到安装目录，管理员自启迁移需要 Windows 授权。
取消授权会保留原自启入口，可以稍后在安装版中关闭自启，再重新启用。确认新版能启动后，再自行清理旧便携目录。

卸载和数据
在 Windows“已安装的应用”中找到 DailyToolkit，或运行安装目录中以 unins 开头的卸载程序。
卸载清理程序、快捷方式和指向安装目录的自启入口，保留指向便携目录的自启。
笔记、设置和备份位于 %LOCALAPPDATA%\DailyToolkit\，卸载后仍然保留，重新安装可继续使用。
可在浮笺配置中导出文本和打开数据目录。恢复默认设置不会删除笔记正文。
