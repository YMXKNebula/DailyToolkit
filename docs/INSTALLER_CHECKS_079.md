# 0.7.9 安装包检查

本轮先加入安装、卸载和运行新版安装包升级，随后在“关于”页补充软件内更新入口。版本号和配置格式保持 0.7.9，捕获、画质、浮笺交互及保存链没有代码改动。

## 本机已执行

Windows 11 x64，Inno Setup 7.1.0。完整应用构建为 0 警告、0 错误，核心测试 117/117。

`scripts/test-installer.ps1` 完成七组隔离检查：

1. 首次安装、Windows 卸载登记、开始菜单快捷方式、程序文件一致性和运行时许可。
2. 程序拒绝正常退出时，升级停止，文件和登记版本保留，不强制结束进程。
3. 最后一次修改保存后再升级；请求自动重新打开；沿用原目录；阻止旧安装包覆盖更高版本。
4. 程序拒绝退出时，卸载停止，程序、登记和自启入口保留。
5. 卸载清理属于安装目录的普通自启和计划任务、快捷方式，保留自行添加的文件。
6. 卸载保留指向便携目录的自启和计划任务。
7. 普通自启迁移到安装目录，非本程序的同名任务保留。

测试使用独立安装登记、快捷方式和任务名称。0.7.8/0.7.9 为安装元数据测试版本，共用当前程序文件；不代表运行过真实旧版程序的全部升级场景。临时窗口模拟现有正常退出协议和保存拒绝，未改写用户笔记。

管理员迁移的早期测试失败：维护进程缺少静默参数，以及任务注册未成功。已补齐维护进程参数，改用 Windows 任务工具注册 UTF-16 XML。普通权限下的隔离测试确认 UTF-8 输入被拒绝，而 UTF-16 输入成功；安装器生成的 UTF-16 文件也通过 XML 解析检查。

测试脚本在已持有管理员权限的环境中另行检查最高权限任务迁移、仅改变两个路径、保留任务字段和安全描述符，以及卸载清理。管理员专项结果以最终提交的 Actions 记录为准；发布前必须通过。这个检查不等于验证普通权限安装器发起授权的完整流程。本机尚未完成修复后的完整 UAC 流程实测，普通生命周期测试也不包含授权弹窗。

## 发布检查

安装版和便携版使用同一份 `DailyToolkit.exe`。打包脚本检查便携目录和 ZIP 的八个文件及 ZIP 内程序摘要，拒绝夹带用户数据、测试程序或开发输出。两个包使用一个校验文件，同一 Release 分别标为安装版和便携版。

GitHub Actions 在 Windows 环境执行现有构建和测试、两种包的打包及安装生命周期检查。最终结果以对应提交的 Actions 记录为准。

## 未验证的范围

Windows 10、Arm64 模拟运行、普通账号通过另一管理员账号授权、磁盘满或断电时的安装中断、企业策略限制、更多历史安装版本升级尚未实测。长期图形运行、睡眠唤醒和显示器热插拔沿用原审查的未验证状态。

没有执行帧时间或 GPU/CPU 占用对比，不能据此给出量化性能结论。应用捕获、渲染和输入链没有代码改动；安装时新增的资源和等待只在安装、卸载进程中使用。

更新专项使用模拟 HTTP，检查两种发布包选择、版本比较、正式版本过滤、下载校验、取消、文件保留、官方跳转限制、安装路径识别、升级参数和重复点击。测试不执行远端安装程序。真实 GitHub 查询、实际下载与完整的软件内更新过程需要分别记录，不能由模拟测试替代。下载时会有网络、文件写入和 SHA-256 运算，未进行带宽或 CPU 占用量化；不点击更新时没有周期网络请求。

更新入口修订后的本机构建为 0 警告、0 错误，Core 117/117、Desktop 47/47。真实 GitHub 正式版本查询和安装包、便携包下载均完成，文件大小和 SHA-256 通过校验，下载的安装包没有在该网络检查中执行。未来更高版本尚未发布，因此软件内从当前正式版本升级到下一正式版本的完整过程尚未实测；安装器隔离测试检查正常保存退出及自动重启请求。

本轮也补齐旧界面测试的笔记存储参数，统一使用临时目录，防止测试中的界面设置写入用户的默认笔记目录。该调整只涉及测试，正式应用的存储位置和保存规则保持不变。

安装测试不再假设当前用户的 Windows `Run` 项已经存在；写入独立测试值前先检查并创建缺失的项。测试仍只清理自己的值，不删除共享的 `Run` 项。
