# DailyToolkit 0.8.0

新增文件集装箱，将不同文件夹、不同硬盘的文件一起打包。

## 更新内容

- 拖入文件或文件夹，选择 ZIP、7z、TAR，设置压缩等级和保存位置。
- 调整包内名称和目录，添加空文件夹，批量移动或移除条目。
- 默认同时压缩两个任务，最多四个；支持排队、调整顺序、单独取消和重试。切换工具或收进托盘后继续打包。
- 外部软件模式先整理到独立文件夹，再用常用压缩软件打包；完成后可保留或清理。
- 简化剪贴回溯的数据管理，将备份、恢复和重置等操作收进“更多”。

## 下载与更新

| 文件 | 使用方式 |
| --- | --- |
| `DailyToolkit-0.8.0-win-x64-setup.exe` | 运行安装；已有安装版可直接升级 |
| `DailyToolkit-0.8.0-win-x64-portable.zip` | 解压后打开 `DailyToolkit.exe` |
| `SHA256SUMS.txt` | 核对下载文件的 SHA-256 |

无需另外安装 .NET 或压缩软件。已有版本可以在“设置 → 关于”中检查更新。更新会保留笔记、剪贴历史和个人设置。
