# 后台资源管理

## 功能和界面

工具停用时，按各自的保存、取消和释放流程停止后台工作。文件集装箱停用会停止运行和排队任务，保留记录供重新开始；仅关闭窗口时，已提交任务继续。

`ApplicationRuntimeHost` 持有托盘、消息入口和工具控制器。原生隐藏消息窗口不创建 WPF 渲染目标，静默启动不创建主界面。浮笺、剪贴回溯和文件集装箱的设置页按需创建；全部功能关闭并满足安全闲置条件时，完整主窗口及其 HWND 也会释放。重开时按值快照重建界面，见 [0.8.7 检查范围](QUALITY_087.md)。

主界面隐藏约 5 秒后检查一次闲置状态。四项功能全部关闭、任务与保存完成、没有其他可见窗口时，尝试释放完整主界面；界面释放不受可选 GC 的堆大小和冷却限制。普通任务栏最小化不会触发释放。重开时恢复页面、窗口大小、展开、滚动和选区等状态；快照只保存值，不保留控件、窗口、绑定或回调。尚未访问的页面继续延迟创建，待恢复状态可跨越多次释放。

未提交文本、校验错误、撤销或重做记录、待安装下载会阻止回收。导出、下载、弹窗或其他忙碌状态下暂缓自动尝试，实际工作与保存完成事件会重新安排一次检查；重新隐藏时也会检查，不持续轮询。配色草稿不会因界面释放而保存或应用：预设点击即保存，自定义颜色保存后应用。

## 闲置内存回收

旧页卸载和无障碍清理完成后，在 `DispatcherPriority.ApplicationIdle` 再次检查所有条件，然后执行一次阻塞压缩 GC。开始检查时托管堆须为 8–64 MiB，距上次回收须新增至少 8 MiB 分配，且间隔至少一分钟。回收前还会确认预览已停止渲染、资源释放完成，没有本地轮询、保存或工具后台活动。

重新打开界面、退出或释放运行宿主会取消尚未执行的回收。页面已卸载但回收被取消时，下次隐藏可在条件满足后补做。条件不满足或进入冷却时停止本次尝试，没有常驻 GC 轮询，也不修剪工作集。已进入的 GC 无法中途取消，堆大小门槛不代表固定暂停上限。

运行库和渲染缓存仍可能保留。界面可以释放，不表示 Windows 会立即归还全部提交，也不保证任务管理器中的内存降到固定值。

## 预览与无障碍

放大镜预览首帧上传照片，后续复用 GPU 源，首帧上传纹理及时释放。回读直接创建拥有独立像素的冻结位图，减少中间数组；照片缓存不保留解码和格式转换链。原图像素、尺寸和 DPI 保持一致，预览闲置时释放照片、位图和 GPU 资源。

永久卸载的旧页使用微软公开的 [UiaDisconnectProvider](https://learn.microsoft.com/en-us/windows/win32/api/uiautomationcoreapi/nf-uiautomationcoreapi-uiadisconnectprovider) 断开过期无障碍提供程序，避免 COM 缓存继续持有页面。清理在卸载后的空闲消息阶段执行，不在同步消息回调中执行。只处理旧页子树，主窗口、独立工具和重建页继续提供无障碍访问。

## 退出与保存

退出前先检查保存。普通保存检查失败时，恢复已暂停的工具并保留编辑内容。文件集装箱进入实际任务关闭阶段后若发生故障，以保留记录和重试退出为恢复方式；已经取消的任务不会自动继续。

## 自动验证

`scripts/check-quality.ps1` 的后台资源检查覆盖消息入口、自动闲置回收、页面状态和配色草稿、后台任务连续性、取消退出恢复、重开取消回收、补做回收及冷却期间不轮询。页面回收使用弱引用和显式 GC 检查可达性，并检查重建页的无障碍名称和按钮接口；这类额外 GC 只用于正确性测试。

Desktop 测试程序提供以下入口：

```text
--runtime-host-checks
--preview-resource-checks
--background-resource-checks <report.json>
--runtime-memory-profile <report.json>
--runtime-memory-profile-production <report.json>
--runtime-memory-profile-retained <report.json>
```

测试使用私有窗口站、临时数据目录、模拟自启接口和自有压缩进程，不产生实际键鼠输入。私有窗口站拒绝快捷键注册时会明确跳过该项，不算作真实快捷键验证通过。

内存对照应使用独立进程、相同窗口尺寸和等待时间，区分自然 GC、产品主动回收和显式实验，分别记录私有提交、总工作集、私有工作集及托管堆。`--runtime-memory-profile-production` 直接等待产品默认回收，记录次数与耗时。隔离测试的绝对内存不能等同于真实安装、已启用功能和用户数据下的任务管理器数字。

深色主题、宽窄窗口及 100/150/200% DPI 渲染由测试检查。真实混合 DPI、实际快捷键、真实读屏软件、游戏运行、睡眠恢复及安装后的内存需要在相应环境中验收。
