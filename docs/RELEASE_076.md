# DailyToolkit 0.7.6

## 浮笺

- 编辑区增加正文边框，颜色与外框一致，透明度跟随背景。
- “位置”增加“点击浮笺聚焦”，默认关闭，可按自己的习惯开启。
- 结束编辑后隐藏边框、滚动条、隐藏按钮和缩放角。
- 隐藏按钮和缩放角更靠近底部两侧，固定模式也能缩放；可在尺寸旁关闭手动缩放。
- 可移动模式编辑时，顶部中央显示移动横杠。
- 结束编辑后，正文可以利用底部空间多显示几行。
- 外观预览可查看正文边框和操作控件。

可分别选择背景、文字和边框颜色，背景与文字透明度独立调整。笔记自动保存，也可以导出文本。

下载本页 ZIP，解压后运行 `DailyToolkit.exe`。
