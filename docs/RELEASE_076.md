# DailyToolkit 0.7.6

浮笺增加正文边框和可选的点击聚焦，失焦时收起操作控件。

- 正文边框使用外框的颜色和背景透明度，失焦时隐藏；滚动条透明度也跟随背景，失焦后隐藏并停止鼠标交互，文字排版不变。
- 位置设置增加“点击浮笺聚焦”，默认关闭。开启后点击正文、背景或顶部都能编辑，取消聚焦时尝试返回点击前的窗口。
- 隐藏按钮和缩放角移近底部两侧角落，使用圆润轮廓；失焦时隐藏，聚焦后显示。固定模式仍保留缩放角，关闭手动缩放才隐藏。
- 可移动模式聚焦时在顶部中央显示圆润横杠，颜色和透明度跟随边框；固定或失焦时隐藏。
- 失焦后利用底部隐藏控件的空间扩展正文显示区域，聚焦时恢复原有布局。文字起始位置、字号与行距保持正常，空余区域留白。
- 外观设置旁的预览同步显示正文边框、操作控件和聚焦状态。

正文与设置仍保存在本机数据目录，更新不会清空笔记。旧版已经删除的点击聚焦字段不会自动开启新选项。本次未调整屏幕局部放大的捕获和画质算法。
