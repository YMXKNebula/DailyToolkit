# 0.5.5 检查记录

2026-10-06，Windows 本机。

- 构建无警告、无错误；31 项核心检查和 25 项桌面检查通过。
- 收藏夹与设置改为互斥面板，共用进入前的主界面作为返回位置。检查双向切换、反复切换、空收藏夹、增删收藏和保留工具设置；关闭当前面板不再返回另一个面板。真实星形和齿轮按钮的交叉点击及关闭也返回常规导航。
- 左侧设置目录保留主题配色、后台运行、启动和关于。切换动画开关及预览并入主题配色；旧动画路由映射到主题页。
- 增加纯白、深海、暮紫和琥珀，共十二套预设；调整薄荷、海蓝、薰衣草、暖沙和玫瑰的窗口、卡片及侧栏色调。检查全部预设色号及文字对比度。
- 预设按钮仅显示名称。真实预设按钮点选后，整套配色及星形/齿轮按钮、动画颜色一并保存和应用，所有详细配置项同步更新；进入收藏夹与设置后颜色保持一致。
- 按钮/动画颜色加入颜色详细配置草稿，与其他色号一样只更新预览。保存后整体应用，撤销及恢复默认只影响草稿；新实例不会读取未保存的配色，导航及其他设置的保存不会误应用草稿。保存或预设应用失败时，原配色、按钮颜色和草稿均保持。
- 浅色、深色及窄窗口的进入、退出、未完成动画反向切换和改点另一图标仍通过首帧像素连续性、覆盖范围及快照释放检查。
- 本地导出并检查海蓝主题、680 像素宽的深海主题、薰衣草详细配置草稿。预设名称、详细配置和动画设置布局完整；草稿预览与全局配色分离。

本次没有改动屏幕捕获、放大渲染或启动注册代码，没有修改本机自启、触发 UAC、注销或重启。屏幕放大实机输入检查的既有范围及限制见 [0.5.0 检查记录](RELEASE_050_CHECKS.md)。个人设置、预览图片和报告保留在本地，不随源码或便携包上传。
