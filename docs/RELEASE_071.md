# 0.7.1

新增“浮笺”：一个可隐藏、重新聚焦、跨屏移动和长期编辑的悬浮文本窗口。

- 默认 Ctrl+Alt+N 显示/隐藏，Ctrl+Alt+Shift+N 再次聚焦，两套热键可独立设置。
- Esc 或双击顶部手柄、边框退出聚焦，笔记继续显示；自然切换到其它程序时不抢回焦点。
- 固定/移动模式与置顶分别设置，长按手柄并超过拖动距离才移动，右下角可调整尺寸。
- 背景六套预设，字体独立预设；支持颜色、独立透明度、字号、系统字体、粗体和圆角。
- 正文和设置分开保存到用户目录，400 毫秒防抖，隐藏及退出刷盘，保留替换前备份。可导出、打开目录和恢复设置，恢复设置保留正文。
- 接入工具启停、收藏、排序与现有主题。停用释放窗口和热键，隐藏复用窗口，主窗口进入托盘不影响笔记。

没有增加运行时依赖或全局输入钩子。屏幕放大的捕获、画质算法、实时帧调度、GPU 资源和镜像移动核心保持原样。

焦点管理只合法尝试一次恢复窗口；目标关闭或 Windows 拒绝激活时清除本窗口输入焦点并提示。查看 [使用与手动检查说明](FLOATING_NOTES.md)。

管理员自启任务指向其它版本时，打开新目录不再通过该任务启动旧程序；当前版本以普通权限打开并说明如何切换自启。只读取路径，不自动更改任务或个人启动偏好。

实现位于 Core/Notes、Desktop/Notes 和主窗口两个接入文件。数据 ID 为将来多笔记保留入口；后续字体导入可以扩展字体来源、丢失文件回退与授权管理，不需要改变现有正文格式。

## 验证

Windows 本机构建为 0 警告、0 错误；核心检查 116/116、桌面检查 37/37。原有检查没有删减，导航和开关定位改为明确选择屏幕局部放大，单工具数量断言更新为两个工具，并保留单条收藏不可排序的检查。

配置页检查覆盖深浅主题下复选框文字、系统字体首次加载、下拉选择与直接输入字体，以及滚动访问字体预览和数据管理。

真实鼠标检查覆盖正文选词、手动重新聚焦、顶部手柄左右双击、固定模式禁拖和双屏拖动。两块屏幕使用 125% / 150% 缩放，其中副屏位于负坐标；360×420 DIP 窗口分别为 450×525 和 540×630 像素，拖动点换算后的误差小于 1 像素。没有修改真实屏幕排列。

原有放大实机检查覆盖双屏接力、4×/16× 比例预设、固定/移动、滚轮、画质切换与资源复用。捕获、GPU 和算法源码无变化。

自动焦点检查使用独立测试窗口，系统拒绝和无效目标使用可控实现；中文组合取消也有事件检查。真实浏览器、各中文输入法、显示器拔插、上下排列和持续数小时的运行仍需按使用说明人工验收，不计作已完成的实机测试。
