# DailyToolkit 0.7.1

新增“浮笺”，可以把文本笔记留在桌面上，随时记录和编辑。

## 使用

- `Ctrl + Alt + N` 显示或隐藏笔记，`Ctrl + Alt + Shift + N` 重新聚焦已显示的笔记。
- `Esc` 或双击顶部手柄、边框结束编辑，笔记仍留在屏幕上。
- 可移动模式下，长按顶部手柄后拖动；右下角可以调整大小。
- 主窗口留在托盘时仍可使用笔记和快捷键。

## 可调整的设置

- 显示和聚焦快捷键。
- 固定或可移动、是否置顶。
- 背景配色、文字颜色、背景与文字透明度。
- 系统字体、字号、粗体和背景圆角。

笔记自动保存，也可以导出文本或打开数据目录。恢复默认设置不会删除正文。

如果开机自启仍指向旧便携目录，请在新版本中关闭自启，再重新启用。
