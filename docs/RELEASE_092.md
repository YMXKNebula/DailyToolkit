# DailyToolkit 0.9.2

- 内置图片、音视频和文档转换组件，断网可用，无需另装 FFmpeg、LibreOffice、.NET 或 Java。
- 移除转换程序路径设置，解压或安装后直接使用；携带时保留完整软件目录。
- 精简无关组件，保留转换所需的运行库、字体及许可材料。
- 沿用现有界面和转换格式；原文件保留，任务结束或取消后释放本次转换进程。
