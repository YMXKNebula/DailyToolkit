# 文件集装箱

将不同位置的文件收集到一份清单，再打包成压缩包。支持跨分区、不同实体硬盘和已挂载的移动硬盘；不要求来源位于同一块盘。原文件保持不变。

## 快速装载

在软件的“文件集装箱”页面开启功能，按 `Ctrl + Alt + P` 呼出或关闭快速窗口，快捷键可以修改。拖入文件、文件夹，或点击“文件”“文件夹”添加。每项单独显示，选中后可以移除。

窗口底部的“打包”打开独立的详细打包窗口，文件清单保留。“快捷打包”使用设置页中保存的文件名、格式、压缩级别和保存位置，同名输出自动更名。尚未选择保存位置时会询问。两个打包窗口共用文件清单；提交后清单清空，任务在后台继续。

功能设置、快速装载、详细打包三个界面各有独立配色。点击预设预览直接应用并保存；自定义颜色只改变预览，点击“保存配色”后应用。

关闭功能会停用快速窗口和快捷键，已经提交的任务继续执行。

## 资源管理器右键菜单

在设置页勾选“加入‘显示更多选项’”，右击文件或文件夹即可选择“装入文件集装箱”。取消勾选可移除入口。菜单仅为当前 Windows 用户添加，卸载时会移除指向本安装位置的入口。便携版移动位置前请先关闭入口，移动后重新开启。

Windows 11 第一层菜单暂不提供。右键多选受 Windows 传统菜单的 100 项上限限制；更多文件可拖入快速窗口。资源管理器与 DailyToolkit 权限不一致时，文件可能无法送入，请在相同权限下重试。

## 收集和整理

点击“添加文件”“添加文件夹”，或从资源管理器拖入。可以反复添加；同一来源路径只收集一次。同名文件可以自动更名、跳过或取消这次添加。

单独添加的文件放在包根目录；添加文件夹时保留文件夹名称和内部结构。双击包内路径输入框可改名或调整位置。“整理包内文件夹”可以创建空文件夹、移动所选条目。移除和清空仅改变清单。

符号链接、目录联接点及无法读取的来源不会跟随复制，页面会列出原因。

## 内置压缩

选择 ZIP、7z 或 TAR，填写压缩包名称和保存文件夹。ZIP 和 7z 可选不压缩、快速、标准、最大；TAR 仅打包。可以记住保存位置，或每次询问。

同名输出可以覆盖、自动更名、换位置或取消。只有新包通过完整性与清单检查后才提交；失败不会先删除旧压缩包。

普通清单和原有空目录直接读取。复杂包内改名、目录映射或新建包内文件夹会先整理副本，并询问额外空间。

## 外部软件

选择“外部软件”后创建独立工作区。准备完成会自动打开该文件夹，在常用压缩软件中自行选择格式和输出位置。

压缩包应保存在工作区以外。完成后选择“完成并清理”或“完成并保留”；清理会删除工作区中的文件。关闭资源管理器不会清理工作区。

工作区位于 `%LOCALAPPDATA%\DailyToolkit\FilePack\Sessions\`，每个任务各用一个目录。

## 任务和恢复

默认同时压缩两个任务，可选一到四个。超出的任务排队，可以提前、延后或单独取消。准备外部工作区另有一个复制名额，准备完不会占用内置压缩名额。

切换工具、关闭页面或收进托盘时任务继续。退出软件会询问未完成任务；中断任务可以重新开始，不提供断点续压。已准备完成的外部工作区会保留，重新打开后可继续手动操作。

任务清单与设置保存在 `%LOCALAPPDATA%\DailyToolkit\FilePack\`。损坏记录保留原文件，不会自动覆盖。

## 范围

内置引擎为官方 7-Zip Extra 26.04 的独立 `7za.exe`，支持 ZIP、7z 和 TAR；无需另装压缩软件。许可和源码获取说明位于程序目录的 `tools\7zip\`。

来源在执行前后会检查大小和时间。检查发现变化时任务失败；这不能保证识别所有保持相同大小和时间的改写，也不保证文件系统瞬时快照。若文件正被其他程序修改，先保存并停止修改，再打包。

每份清单最多 100,000 项；路径等清单信息过大时，需要拆分任务。不跟随链接，也不会自动控制第三方压缩软件。大批量文件和最大压缩等级会占用磁盘与处理器，可减少并行任务数。
