# 文件集装箱

将不同文件夹、分区或实体硬盘上的文件一起打包，原文件保持不变。

## 快速装载

开启功能后，按 `Ctrl + Alt + P` 呼出快速窗口，快捷键可修改。拖入文件、文件夹，或用按钮添加。

- **打包**：打开详细打包窗口，继续整理清单和配置。
- **快捷打包**：使用设置中保存的名称、格式、压缩级别和位置；同名自动更名。

两窗口共用清单，提交后清单清空，任务在后台继续。关闭功能会停用快速窗口和快捷键，已提交任务继续。

功能设置页使用软件配色；快速窗口、详细窗口分别配色。预设点击即保存，自定义颜色保存后应用。

## 右键菜单

在设置中勾选“加入‘显示更多选项’”，即可右击文件选择“装入文件集装箱”。入口仅添加到当前用户。便携版移动目录前先关闭入口，移动后重新开启。

Windows 11 第一层菜单暂不支持。传统菜单最多多选 100 项，更多文件请拖入窗口；资源管理器和软件权限需一致。

## 整理与打包

同一来源路径只添加一次。包内重名可自动更名、跳过或取消；包内路径可改名、移动，也可新建空文件夹。移除条目只改变清单。

| 方式 | 说明 |
| --- | --- |
| ZIP、7z | 不压缩、快速、标准、最大 |
| TAR | 仅打包 |
| 外部软件 | 准备工作区后，使用自己的压缩软件处理 |

可记住保存位置或每次询问。同名输出可覆盖、自动更名或换位置；新包检查通过后才替换旧包。

复杂包内路径需临时副本，创建前提示空间用量。外部工作区位于 `%LOCALAPPDATA%\DailyToolkit\FilePack\Sessions\`，压缩包请保存在工作区之外。**清理工作区会删除其中全部文件**，请先移出要保留的内容。

## 任务与限制

默认同时压缩 2 个任务，可设 1–4 个，其余排队。支持取消、重试和调整队列顺序。收进托盘仍继续执行，退出会询问未完成任务；中断后需重新开始。

任务和设置保存在 `%LOCALAPPDATA%\DailyToolkit\FilePack\`。准备完成的外部工作区保留到手动清理。

内置官方 7-Zip Extra 26.04，无需另装压缩软件；许可和源码位于程序目录的 `tools\7zip\`。

每份清单最多 100,000 项，不跟随符号链接、目录联接点。打包前请保存并停止修改源文件；大小和时间检查不能识别所有改写。大批量文件或最大压缩等级较占资源，可减少并行任务数。
