# DailyToolkit 0.8.7

- 全部功能关闭并缩到托盘后，保存和后台工作完成时自动释放主界面，重开恢复页面和窗口状态。
- 修复保存或后台工作结束后未继续释放界面的问题，保留尚未完成的编辑。
- 文件集装箱在管理员模式下新增底部拖入区，最小化或关闭窗口后自动释放接收程序。
- 拖入文件后关闭窗口，会先接收完文件再保存清单；保存失败时保留窗口。
- 文件集装箱设置中的快捷键和打开窗口选择移到上方，两个手动打开按钮移到下方。

管理员模式拖入尚未完成实机验证；原文件列表仍可能显示禁止符号，请使用底部拖入区或添加按钮。
