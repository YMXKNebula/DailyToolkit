# DailyToolkit 0.7.11

剪贴回溯面板更简洁，窗口操作更方便。

## 更新内容

- 顶部左侧最小化、右侧关闭，搜索框移到下方。
- 点击搜索框或按 Ctrl+F 输入。右侧 × 没有边框，有文字时显示，点击即可清空。
- 拖动边框内侧移动窗口，拖动外沿四边或四角调整大小。最小化后可用快捷键重新呼出。
- 重新复制与撤销删除等操作按钮对齐，文本、链接、图片和文件的图标更容易区分。
- 精简放大镜、浮笺、剪贴回溯和通用设置的说明，减少复制、保存、导出和改配色后的重复提示。

## 下载与更新

| 文件 | 使用方式 |
| --- | --- |
| `DailyToolkit-0.7.11-win-x64-setup.exe` | 运行安装；已有安装版可直接升级 |
| `DailyToolkit-0.7.11-win-x64-portable.zip` | 解压后打开 `DailyToolkit.exe` |
| `SHA256SUMS.txt` | 核对下载文件的 SHA-256 |

无需另外安装 .NET。已有版本可以在“设置 → 关于”中检查更新。更新会保留笔记、剪贴历史和个人设置。
