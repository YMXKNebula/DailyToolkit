# 0.5.2 检查记录

2026-10-06，Windows 本机。

- 构建无警告、无错误；31 项核心检查和 23 项桌面检查通过。
- 设置目录在左侧显示主题配色、切换动画、后台运行、启动和关于。检查每项选中状态及真实页面可见性，每次仅显示对应页面；退出设置仍恢复原工具或收藏夹。
- 通用配色和放大框配色使用同一个彩色轮盘控件。真实像素采样显示六种不同颜色，按钮没有省略号或覆盖图标的背景层；现有色块、色号和本机颜色选择器保留。
- DT 字标统一顶横、笔画粗细、底线和圆角；软件、托盘及主题预览使用对应资源。
- 移除“应用启动设置”按钮，保留开机自启、管理员启动和静默启动。选项修改自动保存，初始化和设置目录切换不注册启动项。
- 模拟启动服务验证首次与重新启用授权、自动保存、取消授权后的选项回退、本地保存失败及排队操作。授权取消不会还原同期修改的配色；静默选项变化不重写启动注册、不重复授权、不重启软件。
- 深色主题、浅色主题、680 像素宽的窗口及独立启动页已导出并检查。检查使用临时设置，图片和电脑信息只保存在本地忽略目录。
- 界面重复说明已删减，保留操作标签、必要状态及异常提示；使用说明已同步更新。

启动授权检查使用模拟服务，本次没有实际启用本机自启、触发 UAC、注销或重启。真实登录启动的实测范围及屏幕放大实机输入检查的已知限制见 [0.5.0 检查记录](RELEASE_050_CHECKS.md)。
