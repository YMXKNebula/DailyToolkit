# DailyToolkit 历史版本 0.6.1–0.6.8

这里提供 0.6.1–0.6.8 的 Windows x64 便携版。选择所需版号的 ZIP，解压后运行 `DailyToolkit.exe`，无需另外安装 .NET。

这些版本提供放大镜。0.6.8 使用红绿滑动开关，图标为相连的 DT 字母和 RGB 背景。

`SHA256SUMS.txt` 可用于核对下载文件。

如需浮笺、安装版或软件内检查更新，请 [下载当前版本](https://github.com/YMXKNebula/DailyToolkit/releases/latest)。具体功能与可调设置见 [使用介绍](https://github.com/YMXKNebula/DailyToolkit#readme)。
