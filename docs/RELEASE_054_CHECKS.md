2026-10-06，Windows 本机。

- 构建无警告、无错误；31 项核心检查和 25 项桌面检查通过。
- 新增切换首帧回归检查，修改前能复现大量像素偏移与新页面透出。修正后，进入、退出、未完成动画的反向切换及改点另一图标，首帧均与此前实际显示画面一致；旧画面快照无透明像素。

- 增加浅色、深色、薄荷、海蓝、薰衣草、暖沙、玫瑰和石墨八套预设，检查色号有效性、文字对比度和真实按钮的即时应用、保存及选中状态。
- “颜色详细配置”位于预览下方，默认收起。使用真实色块和保存按钮检查：草稿只更新预览，保存后应用全局；撤销与恢复预览默认不改动全局，保存失败保留草稿及原配色。离开页面不会应用草稿，新实例只读取已保存配色。
- 修改按钮/动画颜色等其他设置时，未保存的主题草稿不会写入设置或进入窗口资源。预设切换会替换草稿，保存自定义配色后取消旧预设的选中状态。
- 已导出并检查预设、窄窗口深色、详细配色草稿及切换首帧；图片与附带报告仅保存在本地忽略目录。预览入口使用临时设置，提前启用灰度文字渲染以避免导出图片的彩色边缘。

本次没有改动屏幕捕获、放大渲染或启动注册代码，没有修改本机自启、触发 UAC、注销或重启。屏幕放大实机输入检查的既有范围及限制见 [0.5.0 检查记录](RELEASE_050_CHECKS.md)。本机设置、报告和截图不随源码或便携包上传。
