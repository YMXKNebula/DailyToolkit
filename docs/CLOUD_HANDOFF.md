## UI 与资源管理

UI 修改前先读 `src/DailyToolkit.Desktop/Theme.xaml`、`src/DailyToolkit.Desktop/Presentation/ThemePalette.cs`、共享模板和代表页面。继承现有背景、前景、间距、动态资源与控件模板，不另建主题系统。

软件及工具的配色均遵循：**预设点击即应用并保存；自定义编辑仅改预览，保存成功后应用。** 自动保存其他设置和正常退出不得顺带提交配色草稿；保存失败保留原应用色和草稿。保留紧凑的小预览，不放大预设控件。

文件集装箱功能设置页使用软件主配色，快速与详细窗口共用工具配色；剪贴历史面板与浮笺保留各自配色。更早版本关于两个打包窗口各自独立配色的说明已过时。

用户优先低占用，可以接受重开界面的短暂等待。关闭功能时释放它的监听、定时器、热键、窗口、采样与后台工作；需要持续工作的已启用功能保持正常行为。用完即释放应与保存、取消、编辑状态保护协作，不能只隐藏界面。

`ApplicationRuntimeHost` 保留原生消息入口、托盘、控制器和模型；静默启动不创建主界面。主窗口隐藏后，所有工具关闭、保存及后台工作完成、没有其他可见工具窗口时可释放完整主界面和 HWND，重开按值快照恢复。实际工作完成事件重新安排检查，不持续轮询或修剪工作集。

主窗口释放不受可选 GC 的堆大小和冷却限制。未完成输入、撤销状态、校验错误、保存失败和配色草稿需要保留；不能因回收自动提交或丢弃。普通任务栏最小化不等于隐藏到托盘。详见 [后台资源管理](IDLE_MEMORY.md) 与 [0.8.7 检查范围](QUALITY_087.md)。

## 现有功能与关键不变量

### 文件集装箱

- 设置页、快速装载窗口和详细打包窗口分开维护，两个工具窗口共用待打包清单。
- 只有功能总开关，设置卡标题旁的重复开关已移除；右键装载选项保留。快捷键设置、快捷键打开窗口选择在卡片上方，两个手动打开按钮在下方。
- 快速窗口标题为横杠，呼出时横杠对准鼠标并受屏幕边界约束；详细窗口恢复用户调整后的位置。
- 快速窗口底部“详细设置”和“开始打包”宽度为 1:3。前者打开详细窗口并保留清单，后者冻结已保存的快捷选项提交任务。
- 默认按压缩完成时的本地时间命名，例如 `集装箱-2026-10-20-12：25.zip`，精确到分钟，使用合法的全角冒号；保留用户自定义名称，同名自动更名。
- **关闭功能**安全取消运行和排队任务，保留记录供重新开始；**只关闭窗口或缩到托盘**不停止已提交的打包任务。这取代早期“功能停用后任务仍继续”的规则。
- 普通权限应能正常使用。管理员模式在窗口底部增加普通权限原生拖入区，保留主进程文件访问与打包能力。原列表仍可能显示禁止符号，不能声称原列表已支持跨权限拖放。
- 接收端仅随可见窗口存在。最小化或关闭前暂停并排空已接收路径，模型处理完再保存；失败恢复接收和窗口。快速、详细窗口可独立接收，清理任务参与后台回收条件。
- 接收 Copy / CF_HDROP，每批最多 100 个绝对路径，有界字节数。同用户、会话、进程映像、权限和 HWND/管道所属进程必须验证，不放宽 ACL、不用全局输入钩子、不触发 UAC 绕过。
- 原文件只读。保留来源去重、Unicode、空目录、包内改名/路径整理，ZIP/7z/TAR、并行 1–4、取消/重试/调序、输出先校验后提交和恢复保护。复杂映射暂存和外部工作区清理需保留空间与归属检查。
- 内置官方 7-Zip Extra 26.04 `7za.exe` 及许可、源码。x64 引擎 SHA-256 `15d4c788c148e3677e2fc1c4a01f191fb6669eba4f6acf8a465f0f1a6f1e1260`，源码包 `6bcfd2679d178174df06d09d50147dd7b5980d7beac896136689dfc9d51e0fd9`；不改名冒充别的引擎。
- 右键入口是当前用户传统菜单，Windows 11 位于“显示更多选项”，第一层菜单未实现。IPC 保留有界请求和同用户限制，回执读取完再复用管道，避免连续多进程装载丢回执。

### 剪贴回溯

- 默认关闭，开启后按 `WM_CLIPBOARDUPDATE` 事件记录，不监听 Ctrl+C、不高频轮询。暂停、退出和功能停用释放资源。
- 支持文本、URL、文件路径和常见图片；完整富文本仍未实现。原生访问使用合适的 STA 线程及有界重试。
- 重新复制历史记录不新增记录、不重排原记录，不修改创建时间。保留操作 ID、序列号和内容识别，不能改成单一全局布尔标记。
- 不自动模拟粘贴，遵循来源隐私标记。Win+V 是否收录由系统决定，恢复内容不允许云剪贴板同步，不承诺识别所有密码。
- SQLite 元数据与独立加密附件，保留事务、恢复和孤立附件清理；不为搜索另建敏感正文的明文索引。缩略图按需加载、有界缓存。
- 文件默认只记路径，缓存开关默认关闭；开启后自动缓存限制内的新文件，关闭后保留已有缓存并按原路径恢复，旧记录可手动缓存。网络路径、链接和云占位文件不自动缓存。
- 缓存临时恢复副本是未加密文件，保留总量限制与最后使用满 24 小时的运行期清理规则；不承诺退出后自动清理或跨电脑解密。
- 保留备注、永久保存、置顶、批量操作、删除撤销、数据清空确认，以及面板鼠标附近呼出、焦点恢复和虚拟化。搜索不在呼出时主动抢焦点。
