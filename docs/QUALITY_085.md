# 0.8.5 检查与验收范围

通用检查入口、报告要求与诊断隐私规则见 [质量检查](QUALITY_084.md)。发布说明见 [0.8.5 更新说明](RELEASE_085.md)。

## 后台与内存

`scripts/check-quality.ps1` 在打包前运行后台资源检查，覆盖以下行为：

- 原生消息入口的创建、消息转发、托盘请求及退出清理。
- 设置页按需创建；卸载后旧页面可以回收，重开保留滚动、选区、表格列和配色草稿。
- 保存、未完成输入、撤销记录、模态窗口与更新下载阻止界面回收。
- 所有工具关闭且保存、捕获和后台任务结束后，隐藏主界面才允许进行一次内存压缩；重开取消排队操作，冷却期间不反复轮询。
- 页面的无障碍清理真正结束后才回收；重建页面仍有名称、按钮类型与操作接口。
- 工具独立窗口、剪贴处理及文件任务不由设置页生命周期中断；退出保存预检失败后恢复已暂停的工具。

内存测量使用新进程、独立数据和固定等待，区分私有提交、私有工作集和托管堆。普通对照不由测试代码强制回收，生产策略的单次回收和显式实验分别记录。共享运行库、渲染缓存和托盘仍有基础占用，不能宣称停用某工具后整个进程归零。

## 图像与界面

预览检查比较新旧回读路径的像素、位图对缓冲和 GPU 生命周期的独立性，以及照片尺寸、DPI 和图像模式。界面检查沿用深色主题、宽窄窗口及 100/150/200% 渲染，确认紧凑预设、自定义预览与保存交互。

## 发布验收

每个发布提交单独检查构建、核心、完整 Desktop、后台资源、诊断、剪贴、配色、文件任务恢复和界面渲染，再核对同一提交生成的安装包、便携包及校验文件。安装生命周期检查仅在可丢弃 CI 环境进行。

私有窗口站拒绝快捷键注册时，必须与旧消息入口的相同系统错误交叉核对并明确跳过；消息转发通过不等于真实快捷键通过。真实读屏、混合 DPI、睡眠恢复、游戏、GPU 丢失、实体磁盘故障、真实旧数据迁移和签名仍需对应环境验证。不得用历史 CI 或模拟渲染替代实机结果。

压缩 GC 会暂停进程的托管执行；仅在满足闲置资格时触发，已进入的回收不可取消，堆大小门槛不能保证固定暂停上限。用户界面、读我文件及发布说明不承诺固定内存数字或节省比例。
