DailyToolkit

解压后运行 DailyToolkit.exe，无需另装 .NET。Windows x64，已在 Windows 11 测试。

默认快捷键（可修改）
放大镜：Ctrl + Shift + F8
浮笺：Ctrl + Alt + N；Ctrl + Alt + Shift + N 切换编辑，Esc 结束编辑。
剪贴回溯：Ctrl + Alt + V
文件集装箱：Ctrl + Alt + P

剪贴回溯默认关闭，开启后持续记录剪贴板，本机加密保存。
复制敏感内容前请暂停记录，无法自动识别所有密码。
文件默认只记路径；开启缓存后保存文件副本，重新复制会生成未加密临时文件。

文件集装箱支持跨磁盘收集文件，打包为 ZIP、7z 或 TAR。
“打包”进入详细窗口，“快捷打包”使用已保存的设置。
关闭窗口不停止已提交任务；关闭功能会停止任务，保留记录供重新开始。
外部工作区清理会删除其中全部文件，请先移出要保留的内容。

配色预设点击即保存，自定义颜色保存后应用。
工具停用后释放运行资源；闲置界面和预览按需回收。
“设置 → 关于”可导出本地诊断报告，不含笔记、剪贴正文或路径，不自动上传。
“设置 → 关于”检查更新，下载新版 ZIP；替换程序前从托盘退出。
数据位于 %LOCALAPPDATA%\DailyToolkit\，更新或移动程序时保留。
移动目录前先关闭自启和右键入口，在新位置重新启用。

放大镜用于带反作弊的游戏时可能导致封号，请谨慎使用。
