DailyToolkit 0.7.9

Windows 桌面工具集：放大镜、浮笺和电脑信息查看。

运行
解压后打开 DailyToolkit.exe，下载包已包含运行环境，无需另外安装 .NET。
重复打开会显示已有窗口。从托盘菜单退出可完全关闭软件。

放大镜
默认 Ctrl + Shift + F8 开启或关闭，在其他程序前台也可以使用。
可修改快捷键，选择按一次切换或按住时放大，开启或关闭滚轮调节。
倍率范围 1.00–16.00×，每步 0.25×，支持滑块、输入框和滚轮。
画质可选性能、清晰、质量、像素。性能优先响应，清晰适合文字与桌面，质量更注重纹理与边缘，像素保留像素边界。
固定模式可点击下方窗口，可移动模式支持拖动、中心吸附和跨屏移动。
尺寸可自定义或选小、中、大预设，宽高比支持跟随屏幕、1:1、16:9、4:3、21:9，边框颜色可以点选或自选。
帧率可跟随画面或设置上限。尺寸、宽高比和帧率请在关闭放大框后修改，其他设置可在照片预览中查看效果。
放大不能还原原画面没有的细节。独占全屏和禁止捕获的画面可能无法显示，HDR 兼容性尚未完整验证。
用于带有反作弊的多人竞技游戏时，可能导致封号。请谨慎使用，后果自负。

浮笺
默认 Ctrl + Alt + N 显示或隐藏，Ctrl + Alt + Shift + N 切换已显示笔记的编辑状态，Esc 结束编辑。
两个快捷键可以分别更改或清空。结束编辑后鼠标穿透到下方程序；可在位置设置中开启“点击浮笺聚焦”，仅左键用于开始编辑。
编辑时按住空白顶部拖动，左下角按钮隐藏笔记，右下角调整大小，固定模式也可以缩放。
可设置固定或可移动、整数宽高、手动缩放、置顶、背景圆角、系统字体、字号和粗体。
提供十套配色，可分别选择背景、文字和编辑边框颜色，背景与文字透明度分别调整。
“聚焦时完全不透明”默认开启，可以关闭。设置旁的预览可查看编辑和非编辑状态。
笔记自动保存，隐藏和正常退出也会保存。保存失败时可立即保存重试或导出文本。

主题和日常设置
配置标题左侧的星标用于收藏，左下角星形打开收藏夹，齿轮打开设置。
工具列表可拖动排序或右键上移、下移，红绿开关控制工具是否启用。
主题提供十二套预设，自定义配色可先预览，再点击“保存配色”应用。
动画速度可调，也可以关闭动画。可设置关闭窗口或最小化时留在托盘。
开机自启支持管理员启动和静默启动，管理员启动需要 Windows 授权，静默启动只显示托盘图标。
移动便携文件夹前请先关闭自启，在新位置重新启用。

电脑详情
查看日期、天气、网络、电源、硬件和软件安装记录，支持搜索、复制摘要和导出 JSON 报告。
信息从 Windows 读取，不上传检测结果；天气取自本机已有的信息，网络流量取自 Windows 统计。
安装记录可能漏掉便携软件和部分商店应用。分享报告前可先查看其中的内容。

更新和数据
在“设置 → 关于”点击“检查更新”，发现新版后点击“更新”，选择新版 ZIP 的保存位置。
下载完成后可打开文件夹，解压新版再运行；如果替换原目录中的程序文件，请先从托盘菜单退出软件。
笔记和设置位于 %LOCALAPPDATA%\DailyToolkit\，更新或移动程序文件夹不会清空数据。
浮笺正文保存在 Notes\default.txt，设置和正文都有 .bak 备份；配置中可导出文本和打开数据目录。
恢复默认设置不会删除笔记正文。
