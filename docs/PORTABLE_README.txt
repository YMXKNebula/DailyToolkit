DailyToolkit 0.7.9

Windows 本地工具集，提供屏幕局部放大、浮笺和电脑信息查看。

运行
这是便携版，解压后打开 DailyToolkit.exe，已包含 .NET 运行环境。
这是便携包，同一 GitHub Release 也提供安装版 EXE。软件没有自动检查或下载更新的功能。便携版更新前先退出软件，再替换程序目录中的文件。笔记和个人设置保存在用户数据目录，不要删除该目录。
2026-10-09 重打包仍使用 0.7.9 版号，包含捕获启动和资源释放修复。
重复打开会恢复已有窗口。--show 可显示首次启动窗口，--exit 可退出后台实例。

屏幕局部放大
默认 Ctrl + Shift + F8，在后台也能使用。切换模式按一次开启、再按一次关闭；按住模式松开即关闭。
点击“开启/关闭放大”的按键框修改快捷键，清空后不占用快捷键，仍可用按钮控制。
倍率为 1.00–16.00×，每步 0.25×。可以用输入框、滑块或滚轮调整；滚轮的零碎增量会累计，框内短暂显示倍率。
画质可选性能、清晰（推荐）、质量、像素。清晰与质量固定使用 100% 清晰度，旧版可调数值不再生效。性能优先响应，质量的 GPU 开销更高，像素保留原始像素边界。
固定模式允许点击下方窗口；可移动模式可按住画面拖动，靠近屏幕中心时吸附。跨屏接力由邻屏镜像框的中心轴触发，鼠标刚进入邻屏不会立即切换。
尺寸可自定义，也可选择按屏幕宽高 20%、30%、40% 计算的小、中、大预设。宽高比支持跟随屏幕、1:1、16:9、4:3、21:9。
比例预设跨屏后自动调整。自定义尺寸在小屏临时缩小，返回大屏恢复。尺寸、宽高比及帧率需在关闭放大框后更改。
框体颜色可以点选或自选，预览和实际边框同步更新。照片预览和实际放大框的位置各自独立。
“恢复默认”会关闭并回中，恢复默认画面设置，保留快捷键、按键模式和收藏。
帧率默认跟随 Windows 提供的新画面，也可设置上限。实际速度取决于系统捕获、显示器和显卡。
游戏建议使用窗口或无边框模式。放大不能恢复原画面没有的细节，HDR 和独占全屏仍需进一步验证。
用于带有反作弊的多人竞技游戏时，可能导致封号。请谨慎使用，后果自负。

浮笺
默认 Ctrl + Alt + N 显示/隐藏；Ctrl + Alt + Shift + N 切换已显示笔记的聚焦状态。两个快捷键可单独更改或清空。
聚焦显示外框和正文边框，默认完全不透明；再次按聚焦快捷键或 Esc 取消聚焦，并尝试返回此前窗口。失焦时鼠标操作穿透到下方程序。位置设置可开启“点击浮笺聚焦”，默认关闭；开启后只接收左键聚焦，右键、中键和滚轮仍穿透。编辑时双击正文可选词。
聚焦且可移动时按住顶部即可拖动，支持跨屏；顶部中央显示圆润横杠。聚焦时左下角按钮隐藏笔记、右下角调整尺寸，两个控件只显示标记，没有底色或外边框，固定模式也能缩放。宽高以整数保存，“允许拖动右下角调整大小”可以关闭。
十套配色同时设置背景、文字和聚焦边框；颜色可点选或打开颜色对话框选择。支持独立透明度、系统字体、字号、粗体、圆角和始终置顶。
背景、字体和预览在同一个外观区域，预览可切换聚焦/失焦效果。正文边框和滚动条使用背景透明度。失焦时隐藏边框、滚动条、底部按钮和移动提示，并恢复设置的透明度。
失焦时停止拖动、缩放、滚动和选词。正文上下留边与左右一致，多显示原有内容；文字位置、字号和行距保持原样，空余部分留白，聚焦后恢复编辑范围。聚焦时，正文上下有内容被遮挡的边缘静态渐隐，失焦后不使用渐隐。
输入停止约 400 毫秒后保存，隐藏和正常退出保存最后的编辑。数据保存在 %LOCALAPPDATA%/DailyToolkit/Notes/，default.txt 正文与 settings.json 设置分开，并有 .bak 备份。
可立即保存、导出文本、打开数据目录；恢复默认设置保留正文。保存失败时请重试或导出后再退出。
Windows 可能拒绝切换焦点，此时点击想继续使用的窗口；程序不会持续抢焦点。

工具和界面
左侧列出工具，可以拖动排序或右键上移、下移。绿色开关表示启用，红色表示停用，支持点击和左右拖动。
停用会关闭工具并取消快捷键；重新启用只恢复可用状态，不自动开启放大框。
工具配置标题左侧的星标用于收藏；左下角星形打开收藏夹，齿轮打开设置。收藏夹与普通列表使用同一工具状态。
选项切换的圆形波浪从点击位置扩散，作用于选中项和对应配置区。收藏夹和设置使用星形、齿轮展开动画。
主题提供十二套预设。预设点选后生效，自定义色号先更新预览，点击“保存配色”后应用。动画速度可在 0.1–2 倍之间调整，也可关闭动画。
软件、托盘和关于页使用相连的 DT 字母与 RGB 背景图标。关于页显示版本、作者、许可证和项目主页。

启动和后台
可设置关闭窗口或最小化时留在托盘。点击托盘图标恢复窗口，右键可打开设置或退出；后台快捷键仍然有效。
开机自启支持管理员启动和静默启动。管理员自启首次启用及重新启用时需要 UAC 授权；静默启动只显示托盘，两项可以同时使用。
“以管理员权限重启”可立即切换运行权限。启动项和任务仅属于当前用户，不保存密码。
移动便携文件夹前先关闭自启，在新位置重新启用。
旧管理员自启任务指向其它版本时，新程序会以普通权限打开当前版本并提示，不会把启动转回旧程序。要更换自启版本，请在新版中关闭开机自启，再重新启用开机自启和管理员启动。
“以管理员权限重启”只使用指向当前程序的管理员任务；任务路径不同或缺失时，通过 UAC 启动当前程序，取消授权后原程序继续运行。
主窗口进入后台后暂停电脑信息刷新和照片预览，实际放大框的画质、捕获频率与快捷键照常工作。

电脑信息和保存
设置中的“电脑详情”显示日期、天气、网络、电源和配置，支持查看安装记录、搜索、复制摘要和保存 JSON 报告。
天气读取 Windows 本机缓存或任务栏文字，不请求天气服务；网络读取 Windows 状态和流量，不进行联网测速。
安装记录可能漏掉便携软件和部分商店应用。分享报告前，请查看其中的硬件配置、软件名称和本机状态。
设置、收藏和工具顺序保存在 %LOCALAPPDATA%/DailyToolkit/，兼容读取旧版 DailyUSE 设置。
