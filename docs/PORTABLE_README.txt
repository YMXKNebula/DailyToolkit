DailyToolkit 0.7.0

解压后打开 DailyToolkit.exe，已包含 .NET 运行环境。
重复打开会切回正在运行的窗口，不会另外启动一份。

左侧列出各个工具。拖动选项调整顺序，或右键上移、下移。
工具旁的总开关以绿色表示启用、红色表示停用，采用胶囊形滑动开关；绿色启用，白色圆钮在右侧；红色停用，圆钮在左侧。支持点击和左右拖动，圆钮平移与红绿底色过渡同步进行，默认约 180 毫秒。停用会关闭工具、释放资源并取消快捷键注册，再启用只恢复可用状态，不自动开启放大框。收藏夹使用同一状态。
窗口及控件采用圆角，选中项以弧形连接右侧配置区。点击目录时，圆形波浪从鼠标点击的位置向四周扩张，只作用于选中的选项行及右侧对应配置区；边缘使用当前主题强调色的淡渐变，默认约 220 毫秒。
星形与齿轮对称排列在侧栏底部。点击星形打开收藏夹，再点一次关闭，左侧换成收藏的工具。展开时旋转放大并逐渐显现目标页面，关闭时反向旋转缩小并逐渐变回按钮颜色，动画覆盖标题栏下方的整个界面。
右侧齿轮打开设置。收藏夹和设置相互替换，关闭后回到进入前的主界面。左侧设置目录包含主题配色、软件运行、电脑详情和关于；启动与后台选项集中在“软件运行”。主题配色中的“切换动画”可调整速度，范围 0.1–2 倍、步长 0.1 倍、默认 1 倍；页面、星形、齿轮和开关圆钮共用该速度。星形、齿轮和动画颜色随预设同步，也可在颜色详细配置中单独修改。产品图标、版本、作者、许可证与项目主页显示在“关于”。
配色提供浅色、深色、薄荷、海蓝、薰衣草、暖沙、玫瑰、石墨、纯白、深海、暮紫和琥珀十二套预设，预设按钮只显示名称，点选后直接应用并同步详细配置。预览旁的“颜色详细配置”默认收起，窄窗口改为上下排列。界面、按钮/动画、滚动条和调节滑块的色号修改只更新预览，点击“保存配色”后一并应用到整个软件；可撤销修改或恢复预览的默认配色，未保存的色号不会写入个人设置。
点工具里的星标收藏或取消收藏。顺序、收藏和个人设置保存在本机。

后台设置可选择关闭窗口、最小化时留在托盘。点击 DT 托盘图标恢复窗口，右键可打开设置或退出；留在托盘时快捷键仍有效。
软件、托盘与关于页共用相连的纯 DT 字母图标，字母共用连续顶横，底线、笔画与圆角一致，背景为从中心向外旋转铺开的 RGB 渐变。
开机自启下方保留管理员启动与静默启动，修改后直接保存。管理员自启首次启用及关闭后重新启用时请求一次 UAC 授权，之后由已授权任务启动整个软件；静默启动仅显示托盘，两项可以同时启用。当前已是管理员模式时，修改启动设置不再请求授权或重启软件。取消授权或保存失败时恢复原选项。
“以管理员权限重启”可立即切换运行权限。启动项与任务仅属于当前用户，不保存密码。移动便携文件夹前先关闭自启，在新位置重新启用。
使用 --show 可强制显示首次启动的窗口，--exit 可退出后台实例。

设置中的“电脑详情”显示日期、天气、网络、电源和配置。详情和软件列表可展开，支持搜索、复制摘要、保存 JSON 报告。首次打开该页才读取电脑信息，仅在页面位于前台时定时刷新时钟与网络。
窗口转入后台、隐藏或最小化后暂停照片预览，空闲两秒后释放其图形资源，保留最后的预览用于快速恢复；后台快捷键和实际放大框的画质、捕获频率不变。
天气优先读 Windows 小组件的本机缓存，再尝试任务栏天气文字；软件不请求天气服务。网络读取 Windows 状态和网卡流量，不联网测速。

进入“屏幕局部放大”就能看到全部设置，无需下拉展开。
默认 Ctrl + Shift + F8，在后台也能用。切换模式按一次开启、再按一次关闭；按住模式松开即关闭。
点击按键框修改，清空后不占用快捷键，仍可用按钮控制。关闭窗口是否退出取决于后台运行设置；托盘菜单的退出会完全关闭软件。
倍率为 1.00–16.00×，滑块、输入和滚轮均以 0.25× 调节。滚轮零碎增量会累计，框内顶部短暂显示倍率，停止滚动约 0.8 秒后消失。
画质可选择性能、清晰（推荐）、高质量和像素；清晰与高质量可调整 0–100 的清晰度，默认 35。倍率、画质、清晰度随设置保存。开启时切换画质不重建捕获。AI 尚未提供产品选项。
框体颜色可点色块或自选，立即应用到预览和屏幕上的边框。
尺寸预设按屏幕宽高的 20%、30%、40% 计算，宽高比可选跟随屏幕、1:1、16:9、4:3、21:9；所选比例等比放进对应尺寸范围，跨屏后按目标屏重新计算。自定义模式仍可分别设置宽高并保留原值。大小、宽高比和帧率需要在关闭放大框后更改。
默认固定，保留框和采样位置的偏移，可以点击下方窗口，画面继续刷新。可移动时，按住左键拖动画面任意位置，点击不会传到下方窗口；碰边后仍能查看边缘区域，鼠标到达邻屏对称框的中心轴时才跨屏，靠近中心会吸附。开启时也能切换位置模式，再次选择可移动不会回中。
比例预设跨屏后自动调整，自定义尺寸在小屏临时缩小，返回大屏恢复尺寸。预览和实际框的位置互不影响。
“恢复默认”位于详细设置最下方，会关闭并回中，恢复默认尺寸、倍率、颜色、固定模式、滚轮调节和跟随画面；保留快捷键、按键模式和收藏。
帧率默认跟随 Windows 提供的新画面，也可设置上限。实际速度取决于系统捕获、显示器和显卡。
Windows 允许无边框捕获时，只显示放大框边线，不显示屏幕四周的黄色提示。
游戏建议用窗口或无边框模式。放大不能恢复原画面没有的细节，HDR 和独占全屏尚未全面验证。
屏幕局部放大用于带有反作弊的多人竞技游戏时，可能导致封号。请谨慎使用，后果自负。

软件列表可能漏掉便携软件和部分商店应用。分享报告前请查看其中的硬件配置、软件名称和本机状态。
设置在 %LOCALAPPDATA%/DailyToolkit/，兼容旧版 DailyUSE 的快捷键、模式和收藏。
