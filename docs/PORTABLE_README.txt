DailyUSE 0.3.4

解压后打开 DailyUSE.exe。这个版本已包含 .NET 运行环境。

窗口打开后会在后台读取电脑信息，不需要联网或管理员权限。
首页包含日期、天气、网络、电源和电脑信息。展开配置或安装记录后可以查看详情、筛选软件，首页也能复制摘要和保存 JSON 报告。
日期和网络读取 Windows 数据。天气优先读取 Windows 小组件的本机天气缓存，显示温度、天气、地点和更新时间；缓存由 Windows 更新，DailyUSE 不请求天气服务。没有可用缓存时再尝试读取任务栏天气文字。
导航分为“首页 / 日常 / 游戏 / 收藏夹”。点击工具旁的星标加入收藏夹，重启后保留。
左侧“游戏”页的“屏幕局部放大”收起时只占一行，显示快捷键和模式；点击名称或右侧箭头展开详细设置，宽、高可分别调整。旁边的荷花照片同步预览倍率、尺寸和锐化，离线也能看，没有整屏放大选项。
详细设置的“位置”可选固定／可移动，重启后保留。固定时居中，可移动时拖拽绿色边缘，靠近屏幕中心会吸附并显示黄色辅助线，松开后消失。两种模式都能在框内用滚轮调倍率（1–8×），到上下限仍显示，普通点击可操作下面的窗口。照片预览同步响应位置模式，也能试用拖拽和滚轮。
“回到中心”同时重置实际放大框和预览的位置。“恢复默认”关闭放大框，恢复主显示器、640 × 384 像素、2×、35% 锐化、跟随画面、居中和可移动模式；保留自定义或空快捷键、按住／切换模式和收藏。
帧率默认“跟随画面”，按 Windows 提供的新捕获帧渲染，也可设置 30、60、120、144、240 帧上限。实际帧率仍取决于显示器、Windows 捕获和显卡性能，不保证等于游戏内部帧率。
默认 Ctrl+Shift+F8。“切换”模式按一次开启，再按一次关闭；“按住”模式按住开启，松开组合键中的任意一键就关闭。软件最小化或其他窗口在前台时也能直接呼出，不需要先手动开启。
关闭放大框会停止捕获并释放画面资源，之后可以调整设置；本次运行的拖拽位置和倍率会保留。详细设置中只有一个开启/关闭按钮，后台快捷键仍可再次开启，启动中也能关闭。
点击快捷键框可修改，“清空”可设为无快捷键，快捷键和模式都会保存。完全退出软件后释放快捷键。
建议使用窗口或无边框模式。插值和锐化不能恢复原画面没有的细节，HDR 和独占全屏尚未全面验证。
屏幕局部放大用于带有反作弊的多人竞技游戏时，可能导致封号。请谨慎使用，后果自负。
保存的报告包含硬件配置、软件安装记录和已读取的本机状态，请自行决定是否分享。

软件列表来自 Windows 安装记录，可能不包含便携软件和部分商店应用。
系统限制某项读取时，会显示部分信息不可用，其他页面仍可使用。
