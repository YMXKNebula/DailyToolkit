# DailyToolkit 0.9.1

- 新增“格式转换”，支持本地批量转换图片、PDF、音视频和文档，不调用在线服务或 AI。
- 支持图片转 PDF、PDF 逐页导出、转换取消与失败重试；保留原文件，同名输出自动更名。
- 沿用软件的标题、开关、收藏、排序和主题；停用功能时安全取消任务并释放本次运行资源。

文档转换需要本机 LibreOffice，WebP 和部分音视频格式需要本机 FFmpeg。引擎不随程序捆绑，也不会自动下载。系统音视频转换取决于本机编解码器，复杂文档转换后请检查排版。详见[格式转换说明](FORMAT_CONVERSION.md)。
