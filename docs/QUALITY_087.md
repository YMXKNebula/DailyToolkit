# 0.8.7 检查与验收范围

通用检查见[质量检查](QUALITY_084.md)，既有文件打包、快捷键及配色范围见[0.8.6 检查范围](QUALITY_086.md)。本页补充本次变化，最终结果以发布提交对应的检查报告为准。

## 全部功能关闭后的后台释放

全部工具关闭、主窗口隐藏且保存和工作完成后，释放完整主界面及 HWND，保留原生消息入口、模型和仅含值的界面状态。实际工作完成事件重新安排一次检查，不用持续轮询或工作集修剪。大堆、未访问设置页和 GC 冷却不阻止安全释放 UI；可选单次 GC 仍受分配量、堆大小和冷却限制。

检查隐藏后停用最后功能、实际探测和保存完成、空设置页、大于 64 MiB 的可达堆、重新打开取消回收、GC 冷却和稳定后无轮询。保留未完成编辑、颜色原始输入、撤销状态、失败保存保护，以及页面、尺寸和滚动恢复检查。

内存观察使用独立进程、固定临时数据和私有窗口站，分别记录私有提交、私有工作集、托管堆、窗口和视觉树、CPU 时间及回收次数。不据单轮观察承诺固定内存、全面降幅或其他电脑的表现。运行时仍有常驻成本，不能把功能关闭理解为整个进程占用归零。

## 管理员模式拖入区

高权限工具窗口底部预留独立接收区，由当前 EXE 的普通权限原生分支承载，主进程保留文件收集、访问和打包能力。普通模式沿用 WPF 原入口；高权限原文件列表并没有变成跨权限落点。

启动链检查当前 EXE、Explorer 实际映像、用户、会话及完整性等级；子进程挂起创建并验证后恢复。管道仅授权实际用户，双向验证内核 PID、映像和实际权限；嵌入和解除 HWND 前复核所属进程及存活状态。没有令牌修改、窗口消息过滤放宽、全局输入钩子或自启改动。

接收限制为 Copy、CF_HDROP、最多 100 个绝对路径和有界字节数；不移动或删除原文件。暂停接收后排空已接受批次，确认原模型处理结束才保存和关闭；保存失败恢复接收。窗口最小化、关闭和功能停用会释放自有接收端，后台 UI 回收等待清理任务完成。两个可见工具窗口不互相阻塞。

隔离检查使用私有窗口站、自有 HGLOBAL、真实 OLE 注册和实际接收器回调，覆盖格式、路径/条数/大小、Copy 协商及源文件保留。自有测试进程验证生产管道和 Pump、原模型投递顺序、暂停/恢复、双接收端、快速/详细窗口最小化和重建、关闭与启动取消。测试接收分支不得加载 PresentationFramework 或 PresentationCore。

测试运行器若属于 Low 等其他完整性等级，夹具单独严格比较自身与 worker 的原始用户、会话、映像、完整性和提升状态；生产 medium/high 身份规则不得因此放宽。此同权限测试不等于真实高权限主程序启动普通权限 EXE，更不等于 Explorer 跨权限 OLE 拖放。

## 界面与发布

设置页仅在原卡片内调整顺序，复用 Card、SectionTitle、NavButton、原有按钮/文本框模板和动态资源；没有新增独立主题。原生接收区使用已保存的工具配色及相同字体。继续检查深色、三种快速窗口尺寸和 100/125/150/200% 渲染。

原生区域的屏幕像素捕获仅在显式指定测试输出目录时尝试，并限制自有 HWND/PID/私有桌面。无有效显示像素时明确跳过，不生成替代图。DPI 渲染及嵌入断言不代替实际屏幕、混合 DPI 或原生区域视觉验收。

发布继续核对同一提交的 CI、安装版、便携版、校验文件和实际包内容。安装、升级、卸载仅在可丢弃 CI 环境执行，不操作用户实际安装、数据或自启。

真实 Explorer 跨权限拖入、普通权限辅助 EXE 启动、真实键鼠/UAC、原生接收区实机显示和混合 DPI 尚需对应环境。实体磁盘故障、跨物理卷、睡眠/游戏、GPU 丢失、实际历史数据升级及签名边界沿用前版说明。用户诊断不新增文件路径、笔记/剪贴正文或输入流采集，不自动上传。
