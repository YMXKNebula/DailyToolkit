# DailyToolkit 0.8.6

- 修复文件集装箱接收拖入文件和右键装载时的问题，正常使用无需管理员权限。
- 快速和详细窗口共用配色，详细窗口记住调整后的位置。
- 快速窗口标题改为横杠，对准呼出时的鼠标位置；底部按钮改为“详细设置”和“开始打包”，宽度为 1:3。
- 文件集装箱快捷键可选择打开快速或详细窗口，移除页面标题旁的重复开关。
- 设置新增快捷键总览，各工具提示内部重复、已知 Windows 组合和注册失败。
- 默认按打包完成时间命名，如 `集装箱-2026-10-20-12：25.zip`，保留自定义名称。
