# 0.7.3

浮笺在可移动模式下，按住顶部区域即可拖动，无需等待长按。双击任意位置取消聚焦、点击浮笺再次聚焦现在有独立开关，设置会随笔记保存。关闭双击开关后保留正文选词，关闭点击开关后仍可通过快捷键或设置页按钮聚焦。

位置改为“固定／可移动”单选项，收藏改为快捷键行右侧的星标，与屏幕局部放大排版一致。字体只从本机字体列表选择。外观预览固定在右侧，窄窗口显示在上方；滚动调整设置时仍能看到预览。背景和文字颜色输入框后增加色块。

兼容已有笔记和设置。屏幕局部放大的算法保持现有实现，管理员启动继续使用当前程序路径校验。
