# DailyToolkit 0.7.3

## 浮笺操作

- 可移动模式下，按住顶部区域即可拖动，无需长按等待。
- 增加“点击浮笺再次聚焦”和“双击任意位置取消聚焦”两个独立开关。
- 关闭双击取消聚焦后，可在正文中双击选词。
- 位置通过“固定／可移动”选择，快捷键行旁的星标可加入收藏。
- 字体从本机字体列表选择。

## 外观设置

背景和文字颜色旁显示色块。预览在宽窗口右侧、窄窗口上方，滚动调整选项时仍可查看效果。

显示快捷键默认为 `Ctrl + Alt + N`，聚焦快捷键默认为 `Ctrl + Alt + Shift + N`，两者都可修改。

下载本页 ZIP，解压后运行 `DailyToolkit.exe`。
