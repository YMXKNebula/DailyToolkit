# 剪贴回溯

找回之前复制的文本、链接、图片和文件。

## 开启与暂停

打开工具列表中“剪贴回溯”的开关后开始记录。默认关闭。

复制敏感内容前，可以在“隐私与排除应用”中勾选“暂停监听”，或关闭工具开关。重新打开开关会恢复记录；重启软件会保留此前的暂停状态。暂停期间复制的内容不会补记。

默认按 Ctrl + Alt + V 打开历史面板，再按一次关闭。快捷键可以修改、清空或恢复默认；被其他工具或软件占用时会提示。停用后仍可从设置页的“数据管理”打开历史记录。

面板在鼠标附近显示。点击搜索框或按 Ctrl+F 后输入，右侧 × 清空搜索。顶部左侧按钮最小化，右侧 × 关闭；最小化后可用快捷键重新打开。拖动边框内侧可以移动窗口，拖动外沿四边或四角可以调整大小，再次打开会保留本次运行中调整的大小。

## 查找与重新复制

- 单击选择记录，双击或按 Enter 重新复制。
- Ctrl+F 聚焦搜索框，方向键切换记录，Delete 删除。
- 搜索正文、链接、文件名、路径和备注，不区分大小写。
- 可以按文本、链接、图片或文件筛选。长内容可展开查看。

重新复制会把原内容放入系统剪贴板，不自动粘贴，也不新增记录或改变历史顺序。外部再次复制同样内容时，已有记录会移到最近位置，备注、永久保存和置顶状态会保留。

“历史记录”显示全部记录，置顶项排在前面，其余按最近复制时间排序；“永久保存”只显示主动保存的内容。

## 管理记录

- **永久保存**：不受普通历史的数量、期限和容量清理影响。取消保存后重新按普通规则清理。
- **置顶**：优先显示，与永久保存分别设置。只置顶的记录仍会自动清理。
- **备注**：可以添加、修改或删除，备注不会一起复制。
- **删除**：删除指定记录，不清空系统剪贴板。最近一次删除可在 12 秒内撤销。
- **新建记录**：输入文字直接保存，不写入系统剪贴板。手动记录可以编辑；原始复制内容可通过“复制为新记录”另存。
- **多选**：批量保存、取消保存、置顶或删除。删除永久保存项和批量删除时会先确认。

删除记录后，如果再次从其他软件复制同样内容，可以重新记入历史。

## 图片与文件

常见图片可以记录、预览和重新复制。默认单张图片最多 8 MB，可修改；过大或暂不支持的图片会提示并跳过。文字、图片和文件都能独立保存、置顶、备注和删除。目前不保留完整富文本格式。

文件默认只记录路径，再次复制时使用原文件。文档、视频、压缩包和文件夹都按文件处理，不播放或转码。没有缓存时，原文件删除后无法恢复。

开启“文件夹缓存”后，自动保存大小限制内的新文件副本。旧记录可以在右键菜单或完整内容中选择“缓存 / 更新文件”。成功缓存后，即使原件删除，也能从副本重新复制。

默认单条文件记录最多缓存 100 MB，全部文件缓存最多 200 MB，可在设置中修改。永久保存项也受文件缓存总限额约束。网络文件、符号链接和云占位文件不自动缓存，超限或无法读取时保留路径并提示。

关闭缓存开关后，新文件只记录原路径，重新复制也使用原路径；已有缓存保留。“移除文件缓存”只移除副本，保留路径记录。

缓存原件加密保存。重新复制时会生成供其他软件读取的**未加密临时副本**，完整且未被修改的副本可以复用。最后使用满 24 小时后，会在软件运行且历史库打开时清理；关闭软件期间不会自动删除。临时副本另受文件缓存总限额约束。

清空全部历史会删除缓存与临时副本，已经复制的临时路径也会失效。复制敏感文件前，请暂停监听或关闭缓存。

## 配色与容量

历史面板配色独立于软件主题。十二套预设点击即应用并保存；自定义背景、正文、摘要、边框、按钮、选中项和滚动条颜色只改变预览，点击“保存配色”后应用，也可以撤销修改或恢复默认。Windows 高对比度模式开启时使用系统颜色。

普通历史默认最多 1000 条、保留 30 天、容量上限 200 MB，单条文本上限 1024 KB，均可修改。图片和文件缓存计入普通历史容量。实际磁盘占用还包含备份和临时文件，可以在“数据管理”查看。

## 数据与备份

记录和设置保存在 %LOCALAPPDATA%\DailyToolkit\ClipboardHistory\。

“数据管理 → 更多”提供打开数据目录、清空普通或全部历史、创建加密备份、恢复最近备份。清空操作不能撤销。删除记录、自动清理或清空历史时会移除最近备份，避免恢复已经删除的内容。

恢复备份前请暂停监听。历史库无法读取时会保留原文件并提示；没有备份时，请先保留数据目录再检查问题。

加密数据通常只能由原 Windows 用户在原电脑上读取，直接搬移文件不一定能使用。永久保存不能防止磁盘损坏，需要长期保留的重要资料请另外备份。

## 隐私

记录只在本地保存，不上传或云同步。无法自动识别所有密码、令牌和私人资料；复制敏感内容前，请暂停记录或排除来源应用。

排除应用每行填写一个进程名，如 KeePass.exe。只有能够确定来源时才会匹配。来源明确禁止保存历史的内容会跳过。

重新复制的内容默认不加入 Windows 剪贴板历史（Win+V），可在设置中允许；是否收录仍由 Windows 设置和内容类型决定。重新复制时不允许云剪贴板同步。

连续快速复制时，来不及读取就被后续复制覆盖的内容可能无法记录。大量历史的搜索需要更长时间。
