# 剪贴回溯

记录文本、链接、图片和文件，方便查找和重新复制。默认关闭，开启工具开关后持续记录。

停用后仍可手动查看和复制已有记录，不会恢复监听；关闭面板后释放临时加载的资源。

## 操作

| 操作 | 方式 |
| --- | --- |
| 打开或关闭历史面板 | `Ctrl + Alt + V`，可修改 |
| 搜索 | 点击搜索框或按 `Ctrl + F`；× 清空 |
| 重新复制 | 双击或 `Enter` |
| 选择 / 删除 | 方向键 / `Delete` |
| 关闭 | `Esc` 或右上角 × |
| 移动 / 缩放 | 拖动边框内侧 / 外沿 |

支持按类型筛选，搜索正文、路径和备注，不区分大小写。重新复制不自动粘贴，不新增历史，也不改变排序。外部再次复制相同内容时更新原记录，保留备注、保存和置顶状态。

## 管理记录

- **永久保存**：不受普通历史自动清理影响；取消后恢复普通清理规则。
- **置顶**：排在列表前面，仍可能自动清理。
- **备注**：可搜索，不随原内容复制。
- **删除**：最近一次删除可在 12 秒内撤销，不清空系统剪贴板。
- **新建记录**：直接输入文本保存，不写入系统剪贴板。手动记录可编辑，其他内容用“复制为新记录”。
- **多选**：批量保存、取消保存、置顶或删除。

## 图片与文件缓存

图片支持预览和重新复制，默认单张上限 8 MB。暂不保留完整富文本。

文件、文件夹和视频默认只记路径，原件删除后无法复制。开启“文件夹缓存”后自动缓存限制内的新文件；旧记录可选择“缓存 / 更新文件”。复制优先使用缓存，关闭开关后使用原路径，已有缓存保留。

默认每条最多缓存 100 MB、总量 200 MB，可修改。永久保存项也受缓存限额约束；网络文件、链接和云占位文件不自动缓存。失败或超限时保留路径并提示。

缓存加密保存。重新复制时生成**未加密临时副本**，最后使用满 24 小时后在软件运行、功能开启且历史库打开时清理；退出或停用期间不清理。临时副本也受容量限制。清空全部历史会删除这些副本，已复制的缓存路径随之失效。

## 配色、容量与备份

历史面板可独立配色。预设点击即保存；自定义只改变预览，保存后应用。高对比度模式使用系统颜色。

普通历史默认最多 1000 条、保留 30 天、容量 200 MB，单条文本 1024 KB，均可修改。图片、文件缓存计入普通历史容量；备份和临时文件另占磁盘空间。

数据目录：`%LOCALAPPDATA%\DailyToolkit\ClipboardHistory\`。

“数据管理 → 更多”提供清空历史、打开目录和加密备份。**清空无法撤销**；删除或自动清理会移除最近备份。恢复前暂停监听，备份之后的记录不会自动合并。

加密数据通常仅限原电脑、原 Windows 用户读取。永久保存不代替备份；历史库无法读取时，请保留原文件再检查。

## 隐私

历史仅在本地保存，不上传或云同步。无法识别所有密码；复制敏感内容前请暂停记录。排除应用每行填写一个进程名，如 `KeePass.exe`，来源不明时无法匹配。明确禁止历史保存的内容会跳过。

重新复制默认不进入 Win+V，可在设置中允许，实际收录取决于 Windows；不允许云剪贴板同步。

暂停期间不补记。连续快速复制时，来不及读取就被覆盖的内容可能无法记录。
