# DailyToolkit 0.8.4

- 改善后台占用，停用工具时释放运行资源，闲置界面和预览按需回收。
- 文件集装箱停用时安全停止任务，保留清单与任务记录供重新开始。
- 浮笺回收闲置内容时保留必要编辑会话，重开恢复选区与滚动位置。
- 关于页增加本地诊断报告导出，不含笔记、剪贴正文或文件路径，不自动上传。
