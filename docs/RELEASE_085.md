# DailyToolkit 0.8.5

- 改善托盘闲置时的内存占用，全部功能关闭后按需回收用过的设置页。
- 重开设置页恢复滚动位置和配色草稿，未完成的输入会保留。
- 减少放大镜预览的重复缓存和临时内存分配。
- 退出前的保存检查失败时，恢复已暂停的工具，保留当前编辑内容。
