# 0.8.6 检查与验收范围

通用检查入口和诊断隐私规则见 [质量检查](QUALITY_084.md)，闲置回收规则见 [0.8.5 检查范围](QUALITY_085.md)。发布说明见 [0.8.6 更新说明](RELEASE_086.md)。本页说明检查范围与边界，最终结果以对应发布提交的检查报告为准。

## 文件装载与打包

- 在隔离窗口站使用 WPF 的 OLE 拖放入口，验证快速窗口空白、已有条目及详细网格的命中、事件路由和清单收集。仅在来源允许时返回 Copy，不向来源返回 Move；详细窗口的文本拖放保持。
- 右键装载检查使用自有客户端、同用户和同会话的管道通信，覆盖共享清单、窗口选择、并发请求、延迟确认、截断、超限、超时恢复和释放。保留用户、会话、消息大小与路径数量限制，不更改 UAC、进程令牌或窗口消息过滤。
- 普通权限保留完整使用路径。访问受保护文件仍受 Windows 权限限制；提升运行时，普通资源管理器的拖入可能被 Windows 阻止，文件选择按钮继续可用。
- 完成时间命名检查覆盖跨分钟入队与完成、同分钟输出冲突、最终任务记录、自定义名称和旧任务兼容。压缩及验证完成后，使用同一次本地时间生成 `集装箱-yyyy-MM-dd-HH：mm`，文件名使用允许的全角冒号。
- 保留 ZIP、7z、TAR、压缩级别、并行队列、取消与重试、异常恢复、原件摘要和工作区归属检查。关闭窗口继续已提交任务；关闭功能安全停止运行与排队任务并保留记录。

## 窗口与配色

快速和详细窗口共用一套配色及草稿。检查预设立即保存、自定义仅预览、保存失败和重开恢复；文件集装箱设置页沿用软件主配色。

位置检查使用模拟坐标和边界，确认快速窗口标题横杠对准呼出坐标、屏幕边缘钳制，以及详细窗口位置和尺寸的保存恢复。不调用移动鼠标 API；位置仅在调整完成或关闭等事件保存，不增加轮询。

界面检查覆盖深色、窄窗口和 100/125/150/200% 渲染，核对快速窗口横杠、1:3 按钮、详细窗口标题、共享配色、快捷键窗口选择及总览换行。复用 `Theme.xaml` 的 Card、NavButton、SectionTitle、MutedText、AccentButton 和既有窗口模板，不增加独立配色或控件风格。

## 快捷键与后台

快捷键检查覆盖五项全局动作、软件定义的窗口内操作、内部重复、停用状态、拒绝输入后的原值和内联提示，以及总览导航。已知 Windows 组合采用静态提示；外部占用沿用实际启用或修改时的注册结果，错误 1409 与其他注册失败分别显示。不能据此枚举 Windows 或其他程序的所有快捷键，也不能为停用工具确认外部占用。

提示只监听现有配置和注册事件，不增加定时器、键盘钩子或试注册。后台检查继续覆盖停用释放、保存门槛、页面回收、重开取消回收、任务连续性和预览释放，不承诺固定内存数字或整个进程零占用。

测试使用独立数据和自有进程。用户诊断不新增文件路径、快捷键输入流或文件内容采集，不自动上传报告。历史笔记、剪贴、设置和任务数据保留；真实旧数据升级仍需对应样本验证。

## 发布与未验证场景

发布验收核对同一提交的构建、核心与 Desktop、文件打包、快捷键、后台资源及界面检查，再检查该提交生成的安装包、便携包与校验文件。安装生命周期检查仅在可丢弃 CI 环境执行，不能替代真实安装和全部历史数据迁移验证。

隔离 OLE 路由和管道测试不等于实际资源管理器拖放、跨权限或 UAC 测试。私有窗口站拒绝读取真实鼠标或注册热键时应明确跳过，模拟锚点与消息路由通过不代表真实指针或热键回调通过。模拟 DPI 渲染不等于真实跨屏混合 DPI。真实读屏、实体磁盘故障、跨物理卷、睡眠恢复、全屏游戏、GPU 丢失及代码签名仍需对应环境验证，不用历史结果或模拟检查替代。
