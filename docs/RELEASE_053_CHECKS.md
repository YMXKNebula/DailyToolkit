# 0.5.3 检查记录

2026-10-06，Windows 本机。

- 构建无警告、无错误；31 项核心检查和 23 项桌面检查通过。
- 只读检查本机现有启动任务，确认 Windows 将任务账户返回为账户名。修正后能识别该任务；SID、完整账户名、其他用户及不属于本程序的任务均有检查。任务归属仍按解析后的 SID、说明及动作判断。
- 模拟管理员运行状态，检查启用管理员自启、改回普通自启及关闭自启；选项和本地记录正确保存，不再次授权或重启。原有取消授权回退、并发修改串行处理及静默选项检查通过。
- 星形与齿轮进入时放大、退出时缩小，颜色在同一段运动中渐变。实际中间帧像素检查验证页面与按钮颜色的混合，几何检查验证形状能覆盖所有内容角落；标题栏不受影响。
- 检查颜色更改同步更新两枚按钮、动画与主题预览。两枚图标尺寸相同，按钮在两个等宽列中居中并留有间距；产品信息仅显示在关于页及必要的窗口标题中。
- 连续点击星形与齿轮、动画期间缩放窗口及关闭动画均能清理快照并恢复输入；屏幕捕获与渲染代码没有改动。
- 导出并检查浅色、深色的关于页与主题页，涵盖 680 像素窄窗口和完整窗口；实际中间帧能看到页面颜色与动画填色同时呈现。
- 检查待发布文本中的本机账户标识、个人路径和凭据模式，没有匹配；本地报告、设置、构建产物及预览均排除在版本控制外。已授权的照片素材不含 EXIF 元数据。

本次没有改写本机启动任务、触发 UAC、注销或重启。管理员选项修改使用模拟服务验证；真实登录启动仍需通过系统登录验证。屏幕放大实机输入检查的既有范围及限制见 [0.5.0 检查记录](RELEASE_050_CHECKS.md)。
