# DailyToolkit 0.7.5

## 浮笺编辑

- 聚焦快捷键改为按一次编辑、再按一次结束编辑，默认 `Ctrl + Alt + Shift + N`。
- 移除点击聚焦和双击取消聚焦设置；通过快捷键开始编辑，正文双击用于选词。
- 编辑时显示可自选颜色的边框，默认完全不透明；结束编辑后隐藏边框，使用设定的透明度。

## 大小和外观

- 宽高使用整数，尺寸旁可开关“允许拖动右下角调整大小”。
- 隐藏按钮位于左下角，缩放角位于右下角。
- 提供十套背景、文字和边框配色，也可以分别选择颜色。
- 预览可切换编辑和非编辑效果。字体、字号、粗体、透明度、圆角和置顶可自行设置。

收藏星标移到工具配置标题左侧，图形更大、更圆润。

下载本页 ZIP，解压后运行 `DailyToolkit.exe`。
