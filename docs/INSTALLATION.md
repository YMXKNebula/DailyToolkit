# 安装与更新

[下载最新版](https://github.com/YMXKNebula/DailyToolkit/releases/latest)。包含运行环境，无需另装 .NET；目前提供 Windows x64，已在 Windows 11 x64 测试，Windows 10 尚未完整验证。

| 文件 | 用法 |
| --- | --- |
| `-setup.exe` | 运行安装，已有安装版可直接升级 |
| `-portable.zip` | 解压后运行 `DailyToolkit.exe` |
| `SHA256SUMS.txt` | 核对文件 SHA-256 |

## 安装版

按向导选择目录和快捷方式，默认安装到 `%LOCALAPPDATA%\Programs\DailyToolkit`，仅限当前用户，默认无需管理员权限。

“设置 → 关于 → 检查更新”可下载并校验新版，自动升级后重新打开。检查和下载仅在点击后联网。旧安装包不能覆盖新版本。

更新前会保存笔记并退出。保存失败时，请重试或导出文本后再更新。

## 便携版与迁移

更新时先从托盘退出，再解压新版或替换程序文件。“关于”页也可下载新版 ZIP。

安装版和便携版共用当前用户的数据。移动便携目录前，请关闭自启和文件集装箱右键入口，在新位置重新启用。

改用安装版时，可勾选“将已有的开机自启改为安装版”。管理员自启迁移需要 Windows 授权，取消后保留原入口，可稍后在安装版中重新设置。

## 卸载与数据

在 Windows“已安装的应用”中卸载。卸载清理程序、快捷方式及指向本安装目录的自启和右键入口，保留个人数据及指向其他目录的入口。

数据位于 `%LOCALAPPDATA%\DailyToolkit\`，更新或卸载后保留。删除个人数据前请备份笔记、历史和重要文件。

程序尚未签名，Windows 可能显示“未知发布者”。请从本项目下载页获取文件，可用校验文件核对摘要。
