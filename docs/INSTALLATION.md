# 安装和升级

每个 Release 同时提供两个 Windows x64 包，程序功能和版本号一致，无需另装 .NET。软件内只显示版本号。

| 文件 | 用法 |
| --- | --- |
| `DailyToolkit-<版本>-win-x64-setup.exe` | 安装版，运行安装或升级，在 Windows 中卸载 |
| `DailyToolkit-<版本>-win-x64-portable.zip` | 便携版，解压运行，退出后替换文件升级 |
| `SHA256SUMS.txt` | 两个包的 SHA-256 摘要 |

目前真实设备测试使用 Windows 11 x64。安装器的最低系统检查为 Windows 10 2004，与项目 API 目标一致；Windows 10 和 Arm64 模拟运行尚未验证。系统是否处于支持期还需参照 [.NET 10 支持的系统](https://github.com/dotnet/core/blob/main/release-notes/10.0/supported-os.md)。

## 安装版

默认安装到 `%LOCALAPPDATA%\Programs\DailyToolkit`，只为当前用户安装，不要求管理员权限。开始菜单会创建快捷方式，桌面快捷方式可选。

以后运行新版安装包即可升级，安装位置和快捷方式选择沿用前一次安装。安装程序先请求 DailyToolkit 正常退出并等待程序释放文件；笔记保存失败或程序未退出时停止安装，不能强行结束进程。旧版安装包不能覆盖更高版本。

这一步不加入软件内自动更新。需要升级时，从 Releases 下载新安装包并运行。

## 从便携版迁移

安装版和便携版共用 `%LOCALAPPDATA%\DailyToolkit` 中的笔记和设置，同一用户只运行一个实例。安装不会删除旧便携目录。

如果已有自启入口指向另一目录，安装向导提供“将已有的开机自启改为安装版”选项。只迁移能确认属于当前用户和 DailyToolkit 的启动项或计划任务。管理员任务迁移需要 Windows 授权，保留原任务的触发器、权限、静默参数和电源设置，仅改程序路径和工作目录。

取消授权时不会迁移管理员自启任务。迁移失败会给出提示，请在安装版设置中关闭后重新启用自启，并确认实际路径已更新，再自行清理旧便携目录。同一目录的后续安装升级不需要迁移或再次授权。

## 卸载和数据

在 Windows“已安装的应用”中找到 DailyToolkit，也可以运行安装目录内以 `unins` 开头的卸载程序。

卸载先请求安装版正常退出，然后清理安装记录、程序文件、快捷方式，以及仍指向本安装目录的 DailyToolkit 自启入口。自启入口清理失败时停止卸载，保留程序文件供用户关闭自启后重试。指向便携版的自启入口和正在运行的便携版保留。

卸载不删除笔记、设置或 `.bak` 备份，重新安装会继续使用。若要彻底删除数据，请先备份笔记，再自行删除 `%LOCALAPPDATA%\DailyToolkit`。安装目录中自行添加的文件也不会被递归清除。

当前程序和安装包未进行代码签名。安装时 Windows 可能显示未知发布者；包的摘要可核对，但不代替发布者签名。

## 打包和发布

先从 [Inno Setup 官方网站](https://jrsoftware.org/isdl.php)安装 6.5 或更新版本的编译器。运行 `scripts/publish.ps1`，再运行 `scripts/package-installer.ps1`，也可用 `-Compiler` 指定本地编译器。项目脚本不下载和执行安装工具，GitHub Actions 使用运行环境已有的 Inno Setup。本机本次使用核对过官方摘要和有效签名的 Inno Setup 7.1 便携编译器。

同一个 Release 上传安装包、便携 ZIP 和一个同时包含两者的 `SHA256SUMS.txt`。发布说明分别标为“安装版”和“便携版”，不能将安装包描述为自带自动更新。
