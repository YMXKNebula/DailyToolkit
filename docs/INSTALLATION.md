# 安装、更新和卸载

从 [下载页面](https://github.com/YMXKNebula/DailyToolkit/releases/latest)选择安装版或便携版。下载包已包含运行环境，无需另外安装 .NET。

| 文件名结尾 | 适合的用法 |
| --- | --- |
| `-setup.exe` | 安装到电脑，通过开始菜单打开，在 Windows 设置中卸载 |
| `-portable.zip` | 解压运行，自行管理程序文件夹 |
| `SHA256SUMS.txt` | 核对下载文件的 SHA-256 摘要 |

目前提供 Windows x64 版本，已在 Windows 11 x64 上测试。Windows 10 的完整兼容性尚未验证。

## 安装版

运行安装包，按向导选择安装位置和快捷方式。默认位置为 `%LOCALAPPDATA%\Programs\DailyToolkit`，只为当前用户安装，默认不需要管理员权限。

安装后从开始菜单打开 DailyToolkit。桌面快捷方式可以在安装时选择。

## 检查和安装更新

打开“设置 → 关于”，点击“检查更新”。发现新版后，点击“更新”：

- **安装版**：下载并校验安装包，自动安装到原目录，完成后重新打开软件。
- **便携版**：选择新版 ZIP 的保存位置。下载完成后可点击“打开文件夹”，解压新版再运行。

检查和下载由按钮触发，不在后台定期联网。下载中可以取消；失败时可重试。

安装版也可以直接运行新版安装包升级，原安装位置和快捷方式选择会继续使用。安装前软件会保存笔记并正常退出；如果保存失败，请先重试保存或导出文本，再重新更新。旧版安装包不能覆盖更高版本。

较早下载的 0.7.9 如果没有“检查更新”按钮，请先从下载页面手动安装或替换一次。

## 便携版

把 ZIP 解压到你希望保存程序的位置，运行 `DailyToolkit.exe`。

手动更新时，先从托盘菜单退出软件，再解压新版运行，或替换原目录中的程序文件。笔记和设置位于用户数据目录，不依赖便携文件夹。

移动文件夹前请先关闭开机自启，在新位置运行后再启用。

## 从便携版改用安装版

安装版会读取同一用户已有的笔记和设置。安装向导中的“将已有的开机自启改为安装版”可把自启入口改到安装目录。

如果之前启用了管理员自启，迁移需要 Windows 授权。取消授权会保留原自启入口；可以稍后在安装版设置中关闭自启，再重新启用。确认新版能启动后，再自行清理旧便携目录。

两种版本共用当前用户的自启记录。同一安装目录中的后续升级无需再次迁移路径。

## 卸载

在 Windows“已安装的应用”中找到 DailyToolkit，或运行安装目录里以 `unins` 开头的卸载程序。

卸载会退出安装版，清理程序、快捷方式和指向安装目录的自启入口。指向便携目录的自启仍会保留。如果程序无法退出或自启清理失败，请处理提示中的问题后重试。

笔记、设置和备份留在 `%LOCALAPPDATA%\DailyToolkit\`，重新安装后可以继续使用。安装目录中自行添加的文件也会保留。如果需要删除个人数据，请先导出或备份笔记，再自行删除用户数据目录。

## 下载提示

程序和安装包尚未进行代码签名，Windows 可能显示“未知发布者”。请从本项目下载页面获取文件；`SHA256SUMS.txt` 可用于核对文件摘要。
