# DailyToolkit 0.7.0

2026-10-08。本次发布包含 0.6.1 之后积累的界面改进与屏幕局部放大升级，包括参考 AMD 官方源码的画质修订，以及固定清晰度的配置简化。

## 变化

- 工具总开关改为较小的红绿胶囊，白色圆钮左右滑动，平移与颜色过渡同步；支持点击、拖动、键盘和无障碍切换。收藏夹共用工具状态。
- 收藏夹侧栏使用主题的侧栏底色，避免整栏与选中项的强调色混在一起。
- 选项切换时，圆形波浪从点击位置扩散，只覆盖选中选项及对应配置区，颜色跟随主题。
- 程序、EXE、托盘及关于页共用相连的纯 DT 字母与 RGB 背景图标。
- 屏幕局部放大支持 1.00–16.00×，每步 0.25×；滚轮调节后短暂显示当前倍率，保留精密滚轮的余量与反向输入顺序。
- 增加性能、清晰（默认推荐）、质量、像素四种空间画质模式；清晰和质量固定使用 100% 清晰度并移除滑块，忽略旧版可调数值。倍率与模式保存到本机，旧版高质量设置继续兼容。
- 配置中的快捷键标签改为“开启/关闭放大”；关于页和诊断版号从程序集读取。
- 便携包输出为 `artifacts/DailyToolkit-<版本>-<架构>/` 及对应 ZIP，GitHub Actions 同步收集带版号的包。

原有固定/可移动模式、镜像虚拟框、中心轴跨屏接力和 GPU 捕获链路保留。性能维持原有算法与单次绘制；清晰在原来的重建中融合 [AMD CAS](https://github.com/GPUOpen-Effects/FidelityFX-CAS) 的自适应权重，增加文字边缘响应并限制噪声和光晕，仍只绘制一次。质量使用 36 点 Lanczos-3 保留纹理与字形，结合 [AMD FSR 1 EASU/RCAS](https://github.com/GPUOpen-Effects/FidelityFX-FSR) 处理连续斜边与最终锐化，在源图尺度增加受限边缘对比以改善高倍率偏软的问题，两次绘制之间使用 RGBA16F 纹理。像素仍使用最近邻。产品画面没有 CPU 读回。

## 验证范围

发布源码前的本地构建为 0 警告、0 错误，核心检查 **110/110**，桌面检查 **31/31**。另完成实际捕获、双屏三种比例的 4×/16× 双向接力、输入合并、固定取消、滚轮上下限反向、提示过期及模式资源复用检查。

上述结果属于本地验证。对应提交的远端编译、检查及打包结果以 [GitHub Actions](https://github.com/YMXKNebula/DailyToolkit/actions/workflows/build.yml) 为准。本机报告、个人设置、原始画面与日志不随源码上传。

## 已知限制与 AI 原型

清晰与质量是按放大框需求移植、调整的空间算法，相关 AMD MIT 版权已附在第三方声明中。质量在细密字形上不保证优于清晰模式；像素模式在非整数倍率或子像素移动下会出现最近邻采样的跳变。

实测捕获链未稳定达到 120/144/240 FPS；GPU 绘制时间不能用于替代实际输出 FPS 或端到端延迟。

`tools/DailyToolkit.LensAiPrototype/` 是独立的 FSRCNN-small 2× / ONNX Runtime DirectML 评估工具，未加入主解决方案或产品依赖，便携包没有 AI 模型或推理运行时。已验证 NVIDIA、AMD 的 GPU 执行与 CPU 数值一致性；Intel、实时互操作和产品回退未验证。原型包含 CPU 张量上传与输出读回，未作为正式画质选项。

本次便携包及对应源码可从 [0.7.0 正式发布](https://github.com/YMXKNebula/DailyToolkit/releases/tag/v0.7.0) 获取。历史便携包仍可从 [0.6.1–0.6.8 二进制归档](https://github.com/YMXKNebula/DailyToolkit/releases/tag/archive-0.6.1-0.6.8) 获取；该历史标签保留原来的源代码基线。
