# DailyToolkit 0.7.0

## 放大镜

- 倍率范围扩大到 1.00–16.00×，每步 0.25×，可用滑块、输入框或滚轮调节。
- 滚轮调节时短暂显示当前倍率。
- 提供性能、清晰、质量、像素四种画质模式：性能优先响应，清晰适合文字与桌面，质量更注重纹理与边缘，像素保留像素边界。
- 清晰和质量使用固定清晰度，无需另外调整。
- 可设置开启快捷键、按住或切换模式、固定或可移动位置、放大框大小、宽高比和边框颜色。支持跨屏移动。

## 界面

- 工具开关采用红绿滑动样式，可点击或左右拖动切换。
- 选项切换时，圆形波浪从点击位置扩散，颜色跟随主题。
- 调整收藏夹侧栏配色。
- 软件和托盘使用相连的 DT 字母图标，背景为 RGB 配色。

## 使用

下载 ZIP，解压后运行 `DailyToolkit.exe`，无需另外安装 .NET。

默认 `Ctrl + Shift + F8` 开启或关闭放大。画质、倍率和快捷键可在工具配置中修改，主题与动画速度在设置中调整。

放大不能还原原画面没有的细节，实际刷新速度取决于系统和显卡。用于带有反作弊的多人竞技游戏时，可能导致封号，请谨慎使用。
