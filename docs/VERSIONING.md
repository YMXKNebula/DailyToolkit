# 版本号规则

用户于 2026-11-11 指定，版本号为 `a.b.c`：

| 部分 | 含义 |
| --- | --- |
| `a` | 大版本；一个大版本通常安排九个功能阶段 |
| `b=0` | 当前大版本的首个阶段，一般用于优化，不新增功能 |
| `b=1–9` | 功能阶段，每次新增功能后递增 |
| `c` | 工具更新和修复的补丁号，不设固定硬上限 |

`c=0` 仅用于大版本或工具首次发布，之后的补丁递增 `c`。不把补丁号限制为一位数字，例如 `1.2.12` 是有效版本。

例如，`1.0.0` 是大版本首版，`1.1.0` 是该大版本的首个功能发布，随后可有 `1.1.1`、`1.1.2`；下一项功能进入 `1.2.0`。大版本通常经过 `b=1–9` 的功能阶段，具体发布时间和内容仍由当前任务决定，不自动生成未来版本或新增其他发布规则。

本轮格式转换版本按用户明确指定为 **0.9.1**，不自动改为 0.9.0。历史标签、已发布附件及其校验文件保留原样，不按新规则重新编号。
