# DailyToolkit 0.7.10

新增“剪贴回溯”，找回之前复制的文本、链接、图片和文件。

## 剪贴回溯

- 打开工具开关后自动记录，默认按 `Ctrl + Alt + V` 呼出历史面板，快捷键可以修改。
- 搜索正文、文件路径和备注；双击或按 Enter 重新复制，保持历史顺序。
- 单独永久保存、置顶、添加备注或删除记录，删除后可在 12 秒内撤销。
- 手动新建文本记录，支持编辑；多选后可以批量保存、置顶和删除。
- 历史面板可选配色预设或自定义颜色，独立于软件主题。
- 文件默认保存路径。开启“文件夹缓存”后，自动保存限制内的新文件副本；成功缓存的文件在原件删除后仍可重新复制。

功能默认关闭，记录只在本机加密保存。可暂停记录、排除指定应用或清空历史。无法自动识别所有敏感内容，复制密码等信息前请暂停记录。

普通历史默认最多 1000 条、保留 30 天，永久保存项不受普通历史清理影响。容量和保留期限可以修改。重新复制缓存文件时会生成未加密临时副本，供其他应用读取。

## 下载与更新

| 文件 | 使用方式 |
| --- | --- |
| `DailyToolkit-0.7.10-win-x64-setup.exe` | 运行安装；已有安装版可直接升级 |
| `DailyToolkit-0.7.10-win-x64-portable.zip` | 解压后打开 `DailyToolkit.exe` |
| `SHA256SUMS.txt` | 核对下载文件的 SHA-256 |

无需另外安装 .NET。已有版本可以在“设置 → 关于”中检查更新；没有更新入口的旧版请手动下载安装。更新会保留笔记、历史记录和设置。
