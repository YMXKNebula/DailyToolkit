# DailyToolkit 0.8.2

修复文件集装箱的配色和窗口操作。

## 更新内容

- 功能设置页与软件主配色保持一致，修复深色界面中出现大面积浅色背景的问题。
- 快速窗口的最小化按钮移至左上角，关闭按钮位于右上角。
- 快速窗口和详细打包窗口仍可分别设置配色。预设点击即保存，自定义颜色保存后应用。
- 更换快捷键、恢复注册成功或清空组合后，清除旧的冲突提示。
- 改善从资源管理器连续装载多项文件的稳定性。

## 下载与更新

| 文件 | 使用方式 |
| --- | --- |
| `DailyToolkit-0.8.2-win-x64-setup.exe` | 运行安装；已有安装版可直接升级 |
| `DailyToolkit-0.8.2-win-x64-portable.zip` | 解压后打开 `DailyToolkit.exe` |
| `SHA256SUMS.txt` | 核对下载文件的 SHA-256 |

已有版本可在“设置 → 关于”中检查更新，笔记、剪贴历史和个人设置会保留。无需另外安装 .NET 或压缩软件。
