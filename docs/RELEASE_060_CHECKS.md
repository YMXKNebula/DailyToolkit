# 0.6.0 检查记录

2026-10-07，Windows 本机。

## 修改

- 放大框新增小、中、大三种屏幕比例预设，以及跟随屏幕、1:1、16:9、4:3、21:9 宽高比。跨屏接力时按目标屏幕重新计算尺寸，原有自定义尺寸保留。
- 滚动条和滑块的滑块、轨道颜色随主题预设设置，也可在颜色详细配置中独立修改。详细配置与预览并排显示；窄窗口中改为上下排列。编辑仅更新预览，保存后应用。
- 左侧选中项与右侧面板通过圆弧连接，窗口、选项和输入控件使用圆角。选项切换使用约 220 毫秒的波浪过渡，收藏夹内同样适用；快速连续切换从当前画面继续，标题栏不参与。
- 工具旁的总开关使用约 130 毫秒的红绿过渡。停用后关闭放大框并注销快捷键，仍可查看设置；重新启用不会自动开启放大框。收藏夹与主目录共用同一功能状态。
- 电脑页面移入设置，名称为“电脑详情”。首次打开时读取电脑信息；窗口失去前台状态、最小化或隐藏后停止周期轮询。
- 静态照片预览在后台停止更新，约两秒后释放预览 GPU 资源，保留上次位图以便立即显示。实际放大框、全局快捷键和捕获帧处理不受这一策略影响。

## 验证

- 构建无警告、无错误。核心 94/94、桌面 30/30 检查通过。
- 预设计算覆盖横屏、竖屏、不同分辨率、奇数像素尺寸，以及不同尺寸屏幕的双向接力。奇数尺寸使用半像素中心轴，实际鼠标坐标需越过该轴。
- 四项真实捕获检查通过，包括已有解耦与接力逻辑，以及跟随屏幕、1:1、16:9 预设在两块屏幕间往返调整。输出像素、所选框体颜色保持正确；原生窗口与指针复用，只有尺寸变化时重建渲染器。
- 真实鼠标、快捷键、辅助线及双屏往返诊断的 57 项布尔检查均为真。几何测试的模拟指针与真实鼠标消息隔离；实际输入诊断继续使用真实指针路径。
- 界面检查覆盖浅色、深色、窄窗口和完整窗口；动画开始及中途打断时画面连续，完成后释放截图。滚动条拖动、滑块拖动、下拉选择和功能总开关均经过控件检查。
- 配色详细修改在保存前只影响预览，保存后更新实际控件。旧设置缺少新增颜色字段时沿用原强调色，避免覆盖用户原有配色。
- 后台检查确认电脑轮询与预览更新停止、预览 GPU 资源释放，返回前台能够使用缓存立即显示并恢复预览，全局快捷键保持注册。

实际捕获场景中执行 1200 次往返拖动，最终位置恢复。输入回调中位数小于 0.001 毫秒，P95 约 0.009 毫秒。本项只测量回调处理时间，不代表系统输入到显示器的完整延迟。

着色器、实际画面清晰度处理和帧率策略未修改。圆角外窗使用系统窗口合成，不引入透明分层窗口。测试报告、截图、设备信息和临时设置仅保存在本地忽略目录，不随源代码或便携包上传。未修改本机自启、管理员任务或用户实际配置。
