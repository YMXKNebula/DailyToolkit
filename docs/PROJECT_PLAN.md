# 开发计划

先把主程序搭起来，再按日常需要加工具。

## 已有

- Windows 桌面框架，C# / .NET 10 + WPF。
- 首页合并日常状态和电脑信息，工具使用独立列表。
- 读取 Windows 本机日期、网络状态和网卡流量，尝试读取任务栏已有天气文字。
- 后台读取硬件、系统、运行环境和软件安装记录。
- 根据内存、电量、窗口宽度和高对比度设置做基础适配。
- 工具需求检查，以及其他语言本地程序的 JSON 调用接口。

## 后续

先选一个经常会用到的小工具，写出来用一段时间。接入时补上所需运行环境和不支持的情况。

如果几个工具都用到了同一段功能，再把它整理成公共代码。工具做出来后，补上用法和例子。其他平台和 ARM64 实机验证以后按需要安排。
