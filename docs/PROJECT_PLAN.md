# 开发计划

先把主程序搭起来，再按日常需要加工具。

## 已有

- Windows 桌面框架，C# / .NET 10 + WPF。
- 首页合并日常状态和电脑信息，另有日常、游戏和收藏夹，工具收起时按单行列表展示。
- 工具星标收藏，收藏状态保存在本机，收藏夹直接展开同一工具。
- 读取 Windows 本机日期、网络状态、网卡流量和小组件天气缓存，显示天气的来源及更新时间。
- 后台读取硬件、系统、运行环境和软件安装记录。
- 根据内存、电量、窗口宽度和高对比度设置做基础适配。
- 工具需求检查，以及其他语言本地程序的 JSON 调用接口。
- 独立的“游戏”工具分区，屏幕局部放大、后台呼出、自定义及空快捷键、按住和切换模式。
- 放大框独立宽高、荷花照片实时预览、边缘拖拽、滚轮调倍率，以及跟随捕获帧或自选帧率上限。

## 后续

先选一个经常会用到的小工具，写出来用一段时间。接入时补上所需运行环境和不支持的情况。

如果几个工具都用到了同一段功能，再把它整理成公共代码。工具做出来后，补上用法和例子。其他平台和 ARM64 实机验证以后按需要安排。
