# 开发计划

先把常用功能做出来，用一段时间，再决定加什么。

## 已有

- Windows 本地桌面程序，使用 C# / .NET 10 和 WPF。
- “电脑”页显示日期、天气、网络、电源和配置，支持查看软件、复制摘要、导出报告。
- 左侧直接列出工具，支持拖动排序和右键上移、下移。
- 左下角星形入口打开收藏夹，替换左侧列表；左上方可退出。
- 屏幕局部放大：后台快捷键、按住或切换、固定或拖动、跨屏、中心吸附、滚轮缩放。
- 放大框宽高独立调整，最高 10×，色块及自选颜色，照片预览与实际框使用相同的画面处理。
- 设置、收藏和导航顺序保存在本机。
- 后台检测电脑信息，按内存、电量和窗口宽度调整工作量与界面。
- 本地工具的运行条件检查，以及其他语言程序的 JSON 调用接口。

## 后续

挑一个经常用到的小工具，加进左侧列表。接入时写清楚用途、所需运行环境和用法。

多个工具需要同一段代码时，再整理成公共功能。其他平台和 ARM64 等有实际需求时再做。
