# 开发计划

先把常用功能做出来，用一段时间，再决定加什么。

## 已有

- Windows 本地桌面程序，使用 C# / .NET 10 和 WPF。
- 设置中的“电脑详情”显示日期、天气、网络、电源和配置，支持查看软件、复制摘要、导出报告。
- 左侧直接列出工具，支持拖动排序和右键上移、下移。
- 左下角星形打开收藏夹，左侧切换为收藏列表；展开动画作用于标题栏下方的内容。
- 屏幕局部放大：后台快捷键、按住或切换、固定或拖动、跨屏、中心吸附、滚轮缩放。
- 放大框宽高独立调整，倍率为 1.00–16.00×，每步 0.25×，支持色块和自选颜色；照片预览与实际框使用相同的画面处理。
- 性能、清晰、质量、像素四种画质模式；清晰与质量固定使用 100% 清晰度。
- 浮笺：独立笔记窗口、显示和聚焦快捷键、自动保存、配色、字体、透明度、跨屏移动及失焦鼠标穿透。
- 屏幕比例尺寸预设及 1:1、16:9、4:3、21:9 宽高比，跨屏自动调整。
- 圆角窗口与控件、弧形侧栏连接、从点击位置扩散的局部圆形波浪，以及红绿滑动开关，动画速度可调。
- 启动与后台选项集中在“软件运行”。
- 滚动条和滑块随主题配色，可在预览旁修改色号，保存后应用。
- 进入工具页面直接显示全部设置，无需展开。
- 设置、收藏和导航顺序保存在本机。
- 按需读取电脑详情，按内存、电量和窗口宽度调整工作量与界面；隐藏时停止定时刷新并释放空闲预览图形资源。
- 本地工具的运行条件检查，以及其他语言程序的 JSON 调用接口。

## 后续

先补长时间运行、睡眠恢复、显示器拔插和笔记保存失败的测试。

屏幕放大的自动帧率管理另行开发，保留画质和交互响应；目前仍由用户选择帧率上限。安装版与便携版同步发布并保留用户数据。“关于”页支持手动检查更新：安装版下载校验后自动升级，便携版下载新版 ZIP。完整的安装事务回滚和软件内自动定期检查暂未加入。

后续工具接入左侧列表时，写清楚用途、所需运行环境和用法。

多个工具需要同一段代码时，再整理成公共功能。其他平台和 ARM64 等有实际需求时再做。
