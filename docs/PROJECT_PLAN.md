# 项目规划

## 已确定

- 项目名称：DailyUSE。
- 项目形式：公开的开源仓库，采用 MIT 许可证。
- 产品目标：在统一应用入口中集成自行编写的日常小工具。
- 核心实现自行设计和编写；通用基础依赖按各自许可证使用。

## 待确定

- 第一个工具要解决的具体日常问题。
- 初期支持的平台。
- 应用界面和技术栈。

## 实施顺序

1. 选定一个高频日常问题，写清输入、操作和预期结果。
2. 自行实现第一个工具，完成适当验证并实际使用。
3. 根据实际使用反馈完善界面和功能。
4. 抽取确实被多个工具需要的公共能力，逐步形成统一入口。
5. 在已有模块稳定后增加新工具，并补充使用说明。

具体工具清单在需求明确后再添加。
