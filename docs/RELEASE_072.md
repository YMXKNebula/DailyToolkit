# 0.7.2

包含 [0.7.1 的浮笺功能](RELEASE_071.md)，修复更换便携版本后“以管理员权限重启”打开旧目录、导致新工具消失的问题。

- 管理员任务只有在属于当前用户、启用、具有管理员权限且程序路径等于当前 EXE 时才会用于重启。
- 手动重启遇到旧任务或没有可用任务时，通过 Windows UAC 启动当前 EXE，并显示主窗口。取消授权或启动失败时保留原程序。
- 重新启用管理员自启会检查实际程序路径，旧版本任务需要重新授权后迁移；不会因为存在一个旧任务就跳过授权。
- 普通启动遇到旧任务时仍直接打开当前版本，并明确提示在新版中重新设置自启。

浮笺、笔记保存格式及屏幕放大算法保持现有实现。笔记和个人设置位于用户数据目录，清理旧便携程序目录不会清除笔记。

启动检查覆盖旧/当前路径、禁用任务、低权限任务、任务归属、UAC 参数和取消重启保留原实例；现有核心与桌面回归检查继续保留。

Windows 本机构建 0 警告、0 错误，核心 116/116、桌面 37/37。浮笺、工具启停、收藏、主题、托盘和屏幕放大检查均包含在本轮回归中。
