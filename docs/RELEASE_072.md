# DailyToolkit 0.7.2

提供浮笺，并修复“以管理员权限重启”误打开旧版本、看不到新工具的问题。

## 浮笺

- `Ctrl + Alt + N` 显示或隐藏，`Ctrl + Alt + Shift + N` 重新聚焦；`Esc` 结束编辑，笔记保持显示。
- 可设置固定或可移动、置顶、背景配色、文字颜色、独立透明度、字体、字号、粗体和圆角。
- 可拖动到其他显示器，通过右下角调整大小。
- 自动保存笔记，支持导出文本、打开数据目录和恢复设置。
- 可从工具列表启用、停用、排序或加入收藏。

## 管理员启动

“以管理员权限重启”会打开当前版本。已有自启指向旧目录时，会提示重新设置；需要授权时显示 Windows 管理员确认窗口。取消授权后可以继续使用当前程序。

## 下载

下载本页 ZIP，解压后运行 `DailyToolkit.exe`，无需另外安装 .NET。

笔记与设置保存在 `%LOCALAPPDATA%\DailyToolkit\`，更换便携程序目录不会清空数据。
