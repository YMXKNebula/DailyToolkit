# 放大镜

放大屏幕上的局部区域。默认 `Ctrl + Shift + F8` 开启或关闭，可修改快捷键；停用工具后快捷键暂停。

## 设置

| 设置 | 选项 |
| --- | --- |
| 按键 | 按一次切换，或按住放大、松开关闭 |
| 倍率 | 1.00–16.00×，每步 0.25×；滑块、输入框或滚轮 |
| 画质 | 性能、清晰、质量、像素 |
| 尺寸 | 自定义，或小 / 中 / 大（屏幕宽高的 20% / 30% / 40%） |
| 比例 | 跟随屏幕、1:1、16:9、4:3、21:9 |
| 帧率 | 跟随画面，或 30 / 60 / 120 / 144 / 240 帧上限 |

性能优先速度，清晰适合文字，质量更注重纹理，像素保留像素边界。放大不能还原原图没有的细节。

自定义宽 160–1600、高 120–1200 像素。尺寸、比例和帧率需关闭放大框后修改；实际刷新率取决于显示器、显卡和捕获速度。

框体颜色预设点击即保存。自选颜色只改变照片预览，点击“保存颜色”后应用；右键可撤销修改。

## 移动与预览

- **固定**：鼠标穿透，可操作下方程序。
- **可移动**：拖动画面移动，靠近屏幕中心吸附。

拖到屏幕边缘时，框体停止，采样位置继续移动。跨屏需继续拖到邻屏放大框的中心轴；预设尺寸随目标屏幕调整，空间不足时临时缩小。

设置旁的照片预览可试调倍率、画质和位置，与实际放大框位置独立。

“恢复默认”恢复画面和位置，保留快捷键、按键模式和收藏。

## 使用范围

收进托盘后仍可使用。游戏建议窗口或无边框模式；独占全屏、禁止捕获和部分远程桌面可能无法显示，HDR 尚未完整验证。

> 用于带反作弊的游戏时可能导致封号，请谨慎使用。

画面仅实时显示，不录制、不保存、不上传。部分 Windows 环境会显示系统捕获边框。
