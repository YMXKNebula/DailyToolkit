# 屏幕局部放大

在 DailyUSE 左侧选择“游戏”里的“屏幕局部放大”。收起时只占一行，显示快捷键和模式；点击名称或右侧箭头展开显示器、倍率、宽度、高度、锐化和帧率。宽、高可以分别用滑块或输入像素值调整，宽度范围 160–1600，高度范围 120–1200，实际框不会超过所选显示器。只放大局部框，没有“整个屏幕”复选框。

右侧荷花照片是本机效果预览，使用与实际放大框相同的插值和锐化着色器。上图按所选显示器的比例展示位置及大小，下图显示框内细节；尺寸、倍率和锐化改变时同步更新。可以拖拽照片里的放大框、滚动鼠标试效果。窄窗口会把预览放到设置下方。照片随程序保存，展开设置才读取，不启动屏幕捕获。

照片的使用范围见 [素材说明](../src/DailyUSE.Desktop/Assets/README.md)。

实际浮窗首次出现在显示器中央，拖拽边缘即可移动，不再提供固定或跟随鼠标的选项。鼠标放在框内时用滚轮调倍率，每格 0.25×，范围 1–8×；到达上下限仍保持显示。框内的滚轮用于调倍率，普通点击继续传给下面的窗口；边缘拖拽期间的左键和移动由工具处理。隐藏后不处理框内滚轮或新拖拽，停止捕获或退出时释放鼠标监听。

点亮星标后也能从“收藏夹”打开同一个工具，设置和运行状态共用。收藏列表保存在 `%LOCALAPPDATA%/DailyUSE/favorites.json`，取消星标移出收藏夹，不会删除工具。

放大框不抢焦点，鼠标操作会穿过它。框外保持原来的桌面或游戏画面。游戏建议使用窗口或无边框模式；独占全屏、禁止捕获的画面和某些远程桌面环境可能无法显示。

> 屏幕局部放大用于带有反作弊的多人竞技游戏时，可能导致封号。请谨慎使用，后果自负。

## 快捷键

默认 `Ctrl + Shift + F8`，显示和隐藏共用这一个快捷键。软件启动后就注册，不需要先手动开启放大框；其他软件在前台或 DailyUSE 最小化时也能呼出，不把 DailyUSE 主窗口拉到前台。

- **切换**：按一次显示，再按同一快捷键隐藏。持续按住不会反复切换。
- **按住**：按住组合键时显示，松开其中任意一键就隐藏；在后台也会检查松键。

点击输入框，再按想用的组合键即可修改，按 Esc 退出输入。点击“清空”后显示“无”，不占用快捷键，详细设置中的按钮仍可用。

快捷键和模式保存在本机 `%LOCALAPPDATA%/DailyUSE/gaming.json`，重启后保留。旧版自定义及空快捷键会保留，旧版单独的关闭键不再注册。编辑快捷键时暂停注册；更换按键或模式会隐藏当前放大框，避免保留旧按住状态。系统或其他软件占用按键时会提示，可以另选或清空。

隐藏时暂停渲染，保留捕获资源以便下次快速显示。“停止捕获”释放画面资源，快捷键仍可再次启动。关闭 DailyUSE 窗口会退出软件并释放快捷键；后台使用时保持软件运行或最小化。

## 画面处理

Windows Graphics Capture 负责取得所选显示器的画面，Direct3D 11 在独立浮窗内渲染。原始屏幕由 Windows 和游戏继续显示，DailyUSE 只处理框内的区域，不注入游戏，不修改游戏文件或画面设置。

框内使用 16 点 Catmull-Rom 插值重建像素，再做限制过冲的锐化。它会改善缩放后的平滑度和锐度，但不能重新渲染外部游戏的场景，也不能恢复原图没有的真实细节；不是 AI 超分辨率。

显示与采样均使用屏幕实际像素，支持负坐标的副屏。框保持独立的 GPU 渲染目标，通过 Windows 的捕获排除设置避免浮窗反馈，不发送、录制或保存屏幕内容。只有用户开启工具后才启动捕获，正常启动仍先显示主界面。Windows 可能显示系统的捕获提示边框。

帧率默认“跟随画面”，每次 Windows 提供新捕获帧就渲染，程序不再限制为 60 帧。支持的系统会将捕获的最小更新间隔设为零。也可选 30、60、120、144、240 帧上限。它跟随的是 Windows 捕获帧，不是游戏内部帧率；显示器刷新率、系统捕获速度、框的尺寸和显卡开销仍可能影响结果，不能保证与游戏每帧一一对应。帧缓冲限制为两帧，静止画面的更新频率由系统决定；拖拽或滚轮变化时会用最近画面重新渲染，避免静止画面不响应操作。首次在 SDR 画面上验证，HDR 色彩和独占全屏兼容性还没有覆盖。

## 开发验证

核心检查覆盖局部框尺寸、坐标、副屏边界、快捷键和模式有效性。桌面检查实际编译并执行显卡着色器，以 WARP 验证颜色保持和边缘插值；同时检查单个自定义及空快捷键、模式保存、旧设置迁移、后台窗口注册、原生消息投递、松键隐藏和退出清理。

新增检查覆盖高刷新率输入及限帧时序、照片实际渲染、独立宽高、拖拽边界、滚轮上下限、点击穿透、隐藏后的输入放行，以及预览延迟加载和窄窗口布局。

在本机可运行 `DailyUSE.exe --check-lens <PNG路径>`。这个开发检查短暂显示程序自己的测试窗口，通过真实显示器捕获验证：浮窗显示后仍能取得下面的画面、鼠标穿透、图像更新及资源清理。完成后关闭测试窗口，只保存测试区域的 PNG 和验证结果，不保存整个屏幕。这个检查不能替代具体游戏的运行验证。

`DailyUSE.exe --check-lens-shortcuts <JSON路径>` 在真实桌面验证后台首次呼出、同键显示/隐藏、按住显示、松开隐藏和清空释放。开发检查临时注册并生成 F24 按键，不发送文字或修饰键，不更改用户设置，不保存屏幕画面。放大框和临时注册会在结束后释放。请在交互桌面运行；隔离桌面不能验证真实按键和显示。

捕获 API 和排除设置来自微软公开接口；底层 Direct3D 调用使用 Vortice，算法和工具逻辑由本项目实现。依赖许可证见 `THIRD_PARTY_NOTICES.txt`。
