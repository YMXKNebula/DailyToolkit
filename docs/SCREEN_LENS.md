# 放大镜

在左侧选择“放大镜”即可查看配置。绿色开关表示启用，红色表示停用；停用时关闭放大框并暂停它的快捷键，仍可调整设置。

## 开启和关闭

默认快捷键为 `Ctrl + Shift + F8`，在其他程序前台或 DailyToolkit 留在托盘时也能使用。

- **切换**：按一次开启，再按一次关闭。
- **按住**：按住开启，松开组合键中的任意一键关闭。

点击“开启/关闭放大”的按键框，再按新的组合键即可修改；按 `Esc` 取消。点击“清空”后可以使用配置中的按钮开启或关闭。

更换快捷键或按键模式时，当前放大框会先关闭。

## 倍率与滚轮

倍率为 1.00–16.00×，每步 0.25×，可用滑块、输入框或滚轮调整。

“滚轮调节”默认开启，在放大框内滚动一格调整 0.25×。精密滚轮的小幅滚动会累计，反向滚动会抵消未完成的一格。关闭后仍可使用滑块和输入框。

滚轮调节时，放大框顶部短暂显示当前倍率。倍率和画质选择会自动保存。

## 画质模式

| 模式 | 适合的内容 |
| --- | --- |
| 性能 | 优先速度和响应 |
| 清晰 | 文字、桌面和日常内容 |
| 质量 | 更注重纹理与边缘，显卡开销较高 |
| 像素 | 像素画和需要保留像素边界的内容 |

放大框开启时也可以切换画质。清晰和质量使用固定清晰度，无需另外调整。放大只能处理现有画面，不能还原原图中没有的细节。

## 尺寸、比例和边框

“放大框尺寸”可选自定义、小、中、大。三档预设分别按屏幕宽高的 20%、30%、40% 计算。

宽高比可选跟随屏幕、1:1、16:9、4:3、21:9。固定比例会放入所选尺寸范围，竖屏也可使用。跨屏移动后，预设会按目标屏幕重新计算。

自定义宽度为 160–1600 像素，高度为 120–1200 像素。自定义尺寸在小屏上会临时缩小，返回大屏恢复设定大小。

点击“框体颜色”中的色块或“自选…”选择边框颜色。放大框开启时也能换色，预览与实际边框同步更新。

尺寸、宽高比和帧率需要关闭放大框后修改。

## 位置和跨屏移动

### 固定

固定模式允许鼠标点击下方窗口，适合把放大内容留在屏幕上查看。

切换到固定时，放大框留在当前位置，画面继续实时刷新；再次切换为可移动时可从该位置继续拖动。

### 可移动

按住放大画面的任意位置拖动。此时点击只作用于放大框，不会传到下方窗口。靠近屏幕中心时会吸附，拖远即可脱离；拖动时会显示辅助线。

放大框碰到屏幕边缘后，框会停止向外移动，里面的采样位置仍能沿拖动方向变化。反向拖动时，采样位置先回到框中心，再带着框移动；横向和纵向分别处理。

### 跨屏

开启时使用鼠标所在的屏幕。跨屏拖动时，软件会按两屏边界对称计算邻屏中的放大框位置：

- 左右跨屏，指针到达邻屏放大框的竖直中心轴时切换。
- 上下跨屏，指针到达邻屏放大框的水平中心轴时切换。
- 仅碰到屏幕边缘或刚进入邻屏时不会立即切换，可一直按住左键往返。

比例预设会按目标屏幕调整，自定义尺寸在空间不足时缩小。接力后的采样位置会限制在目标屏幕内，随后继续按普通拖动和边缘规则移动。

## 预览、收藏和恢复默认

配置旁的照片预览可以试拖动、滚轮和画质设置。预览与实际放大框的位置互不影响；窄窗口中预览显示在设置下方。

点击配置标题左侧的星标加入收藏夹，左下角星形按钮打开收藏夹。切换页面不会关闭放大框。

“恢复默认”会关闭放大框并回到屏幕中心，恢复 640 × 384 像素、2×、绿色边框、固定模式、滚轮调节和跟随画面。快捷键、按键模式和收藏继续使用当前选择。

## 帧率、后台和适用范围

帧率默认“跟随画面”，也可选择 30、60、120、144、240 帧上限。实际刷新速度取决于 Windows 捕获、显示器、显卡和放大框大小，不能保证等于游戏帧率。

主窗口留在托盘时，放大框和快捷键仍会运行。更换主题或查看其他工具不会关闭放大框。

游戏建议使用窗口或无边框模式。独占全屏、禁止捕获的画面和部分远程桌面环境可能无法显示；HDR 兼容性尚未完整验证。

> 用于带有反作弊的多人竞技游戏时，可能导致封号。请谨慎使用，后果自负。

屏幕画面仅用于实时显示，不录制、不保存、不上传。部分 Windows 环境可能仍显示系统捕获边框。
