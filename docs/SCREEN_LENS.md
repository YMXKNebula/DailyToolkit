# 屏幕局部放大

在左侧点击“屏幕局部放大”，快捷键、按键模式和全部设置直接显示，无需下拉展开。

## 开启和关闭

默认快捷键是 `Ctrl + Shift + F8`，在其他软件前台或 DailyToolkit 最小化时也能用。

- **切换**：按一次开启，再按一次关闭。一直按住不会反复切换，启动中也能关闭。
- **按住**：按住开启，松开组合键中的任意一键就关闭。

点击按键框，再按新的组合键即可修改，按 Esc 取消。点击“清空”后不占用快捷键，详细设置里的按钮仍能开启和关闭。

关闭放大框会停止捕获并释放资源，后台快捷键仍可再次开启。软件设置中可选择关闭窗口或最小化时留在托盘；留在托盘时放大与快捷键继续运行，从托盘菜单退出才会完全关闭。更换快捷键或按键模式会先关闭当前放大框。

重复打开 DailyToolkit 会切回原来的窗口，最小化的窗口会恢复。快捷键和设置由同一份程序处理。

## 设置

倍率范围是 1–10×。“滚轮调节”默认开启，框内每格滚轮改变 0.25×，到达上下限仍显示。关闭滚轮后，滑块照常可用。

宽度范围为 160–1600 像素，高度为 120–1200 像素，可分别用滑块或输入框调整。大小和帧率请在关闭放大框后更改。

“框体颜色”提供常用色块，“自选…”可以选择任意 RGB 颜色。开启时也能更换颜色，预览和屏幕上的边框同步更新；画面内容不受影响，重启后保留选择。

右侧荷花照片展示大小、位置和框内细节，使用与实际放大框相同的画面处理。窄窗口会把预览放到设置下方。照片随软件保存，进入工具页面时读取，不启动屏幕捕获。照片使用范围见 [素材说明](../src/DailyToolkit.Desktop/Assets/README.md)。

## 移动和跨屏

默认“固定”，只锁住当前位置，鼠标点击可以操作下面的窗口。

选择“可移动”后，按住左键拖动放大画面的任意位置。相同的鼠标位移产生相同的采样位移，按下的位置不会改变采样中心。点击只作用于浮窗，不会传到下方窗口。靠近屏幕中心时吸附，拖远即可脱离；辅助线只在拖动时显示，避开放大内容。

框碰到左、右边缘时，框的横向位置停止，采样位置仍能沿横向继续移动；顶部、底部同理。两方向独立，实际采样区域始终留在当前屏幕内。反向拖动时，采样中心先回到框中心，再带着框移动；一次移动中的剩余位移会继续使用。中心吸附是这套位移规则的例外，保留原有 24 像素范围。

开启时自动使用鼠标所在屏幕。跨屏时先计算邻屏上的镜像框，镜像位置沿两屏交界线与原框对称；目标屏放不下时限制在屏内。镜像框不可见，不提前捕获或渲染邻屏。框碰边或鼠标刚进入邻屏都不会切换；左右跨屏要等鼠标碰到镜像框的竖直中心轴，上下跨屏则等待水平中心轴。可以一直按住左键往返，进入较小屏幕时临时缩小，返回大屏时恢复设定尺寸。

接力后，跨屏方向的采样中心与框中心重合。另一方向未碰边时同样重合；碰边时使用鼠标位置作为采样中心，并限制在允许采样的范围。若鼠标位于该边解耦方向的相反侧，则限制到框中心并保持耦合。此后继续执行普通边缘规则。

开启时可以切换固定与可移动。切到固定会保留当前框、采样中心和二者的偏移，画面继续实时刷新；再次选择可移动时从原位置继续，不自动回中。

照片预览也能试拖动和滚轮，预览与实际框的位置互不影响。

最下方“恢复默认”会关闭放大框，将实际框和预览回中，并恢复 640 × 384 像素、2×、默认绿色、固定模式、滚轮调节和跟随画面。快捷键、按键模式和收藏保留。

## 收藏和保存

点亮工具里的星标加入收藏夹。点击左下角星形图标打开收藏夹，再点一次关闭。进入和退出的星形效果相同，覆盖标题栏下面的内容；左侧列表换成收藏的工具。旁边的齿轮用同样的动画打开软件设置，再点一次返回。动画颜色与主题配色在软件设置中调整。切换页面不会关闭放大框。

个人设置保存在 `%LOCALAPPDATA%/DailyToolkit/gaming.json`，收藏在 `favorites.json`，导航顺序在 `navigation.json`。旧版的自定义或空快捷键继续保留，原来单独的关闭键不再使用。

## 画面和限制

帧率默认“跟随画面”，按 Windows 提供的新捕获帧渲染，不固定限制为 60 帧。也可选 30、60、120、144、240 帧上限。实际速度受显示器、系统捕获、放大框大小和显卡影响，不能保证与游戏内部帧率一致。静止画面下调整倍率、位置或颜色，会用最近的画面更新。

游戏建议用窗口或无边框模式。独占全屏、禁止捕获的画面和部分远程桌面环境可能无法显示，HDR 尚未全面验证。

> 屏幕局部放大用于带有反作弊的多人竞技游戏时，可能导致封号。请谨慎使用，后果自负。

工具使用 Windows Graphics Capture 和 Direct3D 11，只处理放大框内的画面。Windows 允许无边框捕获时，不显示屏幕四周的黄色提示；不允许时可能仍有系统边框。屏幕内容不发送、录制或保存。

放大使用 Catmull-Rom 插值和默认细节处理，能改善缩放效果，不能重新渲染外部游戏，也不能恢复原图没有的细节。打开主界面后会在后台准备着色器，减少开启时的等待。每帧直接从捕获进入显卡渲染，不经过界面绑定或照片读回。

## 开发检查

`scripts/build.ps1` 检查设置保存、旧版兼容、导航排序、收藏、快捷键、拖动、照片预览和真实着色器输出。颜色检查要求边框为选定的 RGB 值，框内像素保持不变。

核心检查还覆盖四边立即解耦、重新耦合及剩余位移、采样边界、镜像轴接力、固定冻结、负坐标与不同尺寸屏幕。交互桌面可在构建后运行 `tests/DailyToolkit.Desktop.Tests/bin/Release/net10.0-windows10.0.26100.0/DailyToolkit.Desktop.Tests.exe --live-lens-only`，检查真实 Windows 捕获在固定偏移下继续刷新，以及待切换位置取消、接力时连续位移和资源复用。该检查只显示自有纯色窗口，不生成桌面图片或修改用户设置；单屏时实机跨屏检查明确跳过。

本机交互桌面可运行以下检查，输出目录需先存在：

```powershell
DailyToolkit.exe --check-lens <PNG路径>
DailyToolkit.exe --check-lens-shortcuts <JSON路径>
DailyToolkit.exe --benchmark-lens <JSON路径> <旧版HLSL路径>
```

前两项短暂显示自有测试窗口，验证捕获、真实鼠标点击和拖动、开启时反复切换位置模式、辅助线、资源释放和跨屏往返，只保存测试区域。固定模式的点击应传到测试窗口，可移动模式的点击应被浮窗接住。快捷键检查临时使用 F24，结束后恢复鼠标位置，不修改用户设置。单屏时跨屏结果为 `null`。

基准使用生成的纹理，通过 GPU 时间戳比较处理耗时和像素输出，不包含读回、系统捕获或呈现等待，不能代替游戏中的帧率测试。默认颜色沿用原着色器输出，改色只改变两像素宽的边框。

底层 Direct3D 使用 Vortice，工具逻辑和算法由本项目实现。依赖许可证见 `THIRD_PARTY_NOTICES.txt`。
