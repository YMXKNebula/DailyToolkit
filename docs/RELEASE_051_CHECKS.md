# 0.5.1 检查记录

2026-10-06，Windows 本机。

- 构建无警告、无错误，31 项核心检查和 23 项桌面检查通过。
- 收藏夹与设置打开时旋转展开，关闭时反向旋转收回到各自按钮。实际动画时钟检查确认缩放和旋转的方向，两个方向使用同一填色。
- 打开完全展开、关闭开始收回时，真实像素覆盖内容区四角及中心，标题栏保持原色。关闭的旧页快照保留在形状内部，形状外直接显示目标页面。
- 填色轮廓冻结并使用渲染变换，避免轮廓缩放触发布局测量；缩放、旋转与淡入淡出使用平滑的正弦加减速。每次切换复用一张快照，动画总时长保持 460 毫秒。
- 连续点击星形和齿轮、切换配色、关闭动画、调整窗口大小及完成后的快照和变换清理通过。
- DT 图标改为顶横相接的组合字标，D 左上角和 T 末端斜切。九个 ICO 帧逐一解码检查，尺寸为 16、20、24、32、40、48、64、128、256 像素；明暗背景下的小尺寸预览已检查。
- 导出齿轮回收的实际中间帧并检查，导出使用临时设置，检查图片和电脑信息仅保留在本地忽略目录。

本次更改限于页面动画、DT 图标及对应说明。管理员授权与登录启动的实测范围、屏幕放大实机输入检查的已知限制见 [0.5.0 检查记录](RELEASE_050_CHECKS.md)。
