# DailyToolkit 0.7.12

配色预设即选即用，自选颜色先预览再保存。

## 更新内容

- 剪贴回溯、浮笺和放大镜的配色预设点击后立即应用并保存。
- 自选颜色只改变预览，保存后应用。浮笺使用原有“立即保存”；放大镜在原按钮位置显示“保存颜色”。
- 连续切换预设后，预览与实际配色保持一致。恢复默认背景或字体时保留其他颜色的未保存修改。
- 保存失败时保留原配色和修改内容。各工具仍使用独立配色，设置页保持原有排版。

## 下载与更新

| 文件 | 使用方式 |
| --- | --- |
| `DailyToolkit-0.7.12-win-x64-setup.exe` | 运行安装；已有安装版可直接升级 |
| `DailyToolkit-0.7.12-win-x64-portable.zip` | 解压后打开 `DailyToolkit.exe` |
| `SHA256SUMS.txt` | 核对下载文件的 SHA-256 |

无需另外安装 .NET。已有版本可以在“设置 → 关于”中检查更新。更新会保留笔记、剪贴历史和个人设置。
