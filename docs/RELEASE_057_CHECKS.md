# 0.5.7 检查记录

2026-10-07，Windows 本机。

本次减少屏幕局部放大拖动时的输入阻塞及重复更新。四边解耦、镜像轴接力、固定偏移、中心吸附、画面处理和帧率规则保持。

## 修改

- 鼠标回调立即消费每次位移，窗口移动和采样更新改为处理最新的待显示快照。使用输入优先级，不增加定时等待或新的帧率上限。
- 实际框位置不变时跳过窗口操作；同尺寸移动不重复调整尺寸或 Z 序。
- 辅助线只在首次显示、避让区间或对齐颜色变化时更新，不随每次鼠标输入反复调整 Z 序。
- 相同采样参数不重复请求重绘。如果新的捕获帧已经呈现该组参数，待处理的参数重绘直接跳过。新捕获帧仍照常渲染，着色器及画面处理算法未修改。
- 拖动不反复通知同一条状态文本。倍率、位置模式、滚轮开关和真实捕获切换仍更新状态。

## 本机对照

从 0.5.6 提交建立独立本地副本，只加入同一计时检查，与修改后版本对比。两个版本均运行真实 Windows 捕获、640 × 384 放大框、2× 和自有纯色场景。每次执行 1200 个往返拖动输入，检查所有输入处于拖动状态且最终框位置恢复。

| 回调处理时间 | 0.5.6 | 修改后 |
| --- | --- | --- |
| 中位数 | 1.434 毫秒 | 小于 0.001 毫秒 |
| P95 | 2.156 毫秒 | 0.007 毫秒 |
| P99 | 2.661 毫秒 | 0.021 毫秒 |

这些结果只测量输入处理，不包含完整的系统输入、桌面合成和显示器延迟。渲染计数包含旧画面参数重绘，不能拿它比较源画面的帧率，也不能保证所有游戏或硬件都有相同比例的改善。
