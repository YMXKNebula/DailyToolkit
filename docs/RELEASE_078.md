# DailyToolkit 0.7.8

浮笺失焦时，鼠标操作穿透到下方程序，不再拖动、缩放、滚动或选词，也不会因点击夺走焦点。

- “点击浮笺聚焦”仍在位置设置中，默认关闭。开启后只接收左键来聚焦，右键、中键和滚轮继续穿透；这次左键不会同时拖动、选词或点击下方程序。
- 聚焦时，有内容被遮挡的正文上下边缘静态渐隐：顶部向上变淡，底部向下变淡。没有遮挡的一端保持完整显示，失焦后移除渐隐。
- 隐藏和缩放控件去掉外边框，保留圆润底色与标记；正文边框、浮笺边框和顶部横杠保留。
- 失焦时的上下等距显示、文字位置、字号、行距、换行宽度及聚焦后的滚动恢复保持原样，外观旁预览使用相同渐隐与控件样式。

更新保留本机笔记和设置，固定模式聚焦时仍能缩放。本次未调整屏幕局部放大的捕获和画质算法。

本机检查：构建 0 警告、0 错误，核心 117/117、桌面 38/38。隔离窗口验证正文的实际渐隐渲染；独立进程验证左键、右键、中键和滚轮穿透、左键聚焦与返回此前程序。125%/150% 两屏实测覆盖聚焦拖动、拖动点、整数缩放，以及失焦拖动与缩放阻止。
