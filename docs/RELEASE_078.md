# DailyToolkit 0.7.8

## 浮笺鼠标操作

默认结束编辑后，鼠标操作穿透到下方程序，笔记不会因点击而抢走焦点。

“点击浮笺聚焦”默认关闭。开启后，仅左键用于开始编辑，右键、中键和滚轮仍能操作下方程序；未编辑时不能拖动、缩放、滚动或选词。

## 显示效果

- 编辑长笔记时，被遮挡的正文上下边缘逐渐变淡，提示还有内容可滚动查看。
- 没有遮挡的一端正常显示，结束编辑后不显示渐隐。
- 隐藏和缩放控件去掉外边框，显示圆润底色和图形标记。

可在设置中选择点击聚焦、手动缩放、配色、透明度和字体，旁边的预览可以查看效果。
