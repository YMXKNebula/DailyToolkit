# 0.5.6 检查记录

2026-10-07，Windows 本机。

本次仅调整屏幕局部放大的拖动、四边采样及跨屏接力。快捷键、倍率、滚轮、照片预览、颜色、收藏、设置、托盘和启动行为保持。捕获、GPU 渲染器、着色器及帧率控制代码未修改。

## 行为

- 鼠标按下位置只决定开始拖动；此后消费每次鼠标位移。原生窗口和鼠标钩子观察到同一坐标时不会重复消费。
- X、Y 独立处理耦合、最小边解耦及最大边解耦。渲染框触边立即解耦，采样区域限制在当前捕获屏内。返回中心时只消费回程所需的位移，剩余部分继续推动框，允许同次移动再次碰边。
- 虚拟框沿两屏交界镜像真实框，目标屏放不下时限制在合法范围；有桌面间隙时以相向边的中线镜像。它只持有几何数据。左右接力检查鼠标与虚拟竖直中心轴的交点，上下接力检查水平中心轴。
- 接力后重新确定两轴状态。另一轴碰边时取鼠标坐标并限制采样范围；按用户确认，坐标落在解耦方向相反一侧时限制到框中心并保持耦合。
- 按用户确认保留中心吸附，作为精确位移的例外。吸附期间保留连续小步的累计位移；虚拟框使用吸附后的可见位置做镜像。
- 固定冻结实际显示的框、采样中心及偏移，取消尚未应用的跨屏位置快照。捕获继续刷新，再次选择可移动不回中。

| 文档编号 | 检查 |

| 22–27 | 横向接力后的 Y、纵向接力后的 X 分别覆盖未碰边、最小边和最大边；鼠标相反侧的中心限制；接力后使用普通回程和剩余位移。 |

| 32–33 | 负坐标、桌面间隙、较小且错位的目标屏、尺寸恢复；多屏大位移连续接力。 |

补充真实 Windows 捕获检查 `--live-lens-only` 已通过：

- 固定后连续改变自有测试窗口的颜色，捕获帧数增长且渲染像素匹配新颜色，框及采样区域保持不变。

- 待切换时选择固定，已排队的位置不会移走实际框。接力后紧接着的 17 像素移动、捕获切换时再次收到的返回位移、按住往返均不丢失。
