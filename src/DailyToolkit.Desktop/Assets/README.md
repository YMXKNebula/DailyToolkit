# 预览素材

`dt.svg`、`dt.png`、`dt.ico` 是 DailyToolkit 的 DT 图标，适用项目的 MIT 许可证。矢量源和生成脚本一同提供，软件及托盘使用相同图案。

D 与 T 连在一起，共用顶部横线，背景为从中心旋转展开的 RGB 色带。窗口、关于页和托盘使用相同图案。ICO 包含 16 到 256 像素的九种尺寸，由矢量源分别绘制。

`power-on.png` 与 `power-off.png` 是 0.6.7 旧版工具总开关图片，使用项目的 MIT 许可证，生成脚本为 `scripts/create-power-images.ps1`。从 0.6.8 起，工具开关使用原生胶囊轨道和白色滑动圆钮，这两张图片不再打入当前程序。

`lens-preview.jpg` 是随 DailyToolkit 发布的荷花照片，已获提供者授权，用于普通和放大预览。

照片不适用项目代码的 MIT 许可证。若需用于其他项目，请联系项目作者另行取得授权。
