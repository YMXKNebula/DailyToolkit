DailyToolkit distributes the unmodified official standalone 7za.exe.
It creates ZIP, 7z and TAR without an additional DLL. The official Windows
Extra package calls this binary 7za.exe, not 7zz.exe. Reduced extraction
format support does not affect the three creation formats used by FilePack.

The full GNU LGPL 2.1 text is in COPYING.txt. The exact corresponding official
source is included alongside this file as 7z2604-src.7z (SHA256 below).
This executable runs as a separate process, and users may replace it with
a compatible official build. DailyToolkit does not modify 7-Zip code.
