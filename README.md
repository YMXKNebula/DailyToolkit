# DailyToolkit

Windows 本地工具集，提供屏幕局部放大、浮笺和电脑信息查看，使用 C#、.NET 10 和 WPF。

当前版本为 **0.7.9**，改动见 [更新说明](docs/RELEASE_079.md)。下载地址：[Releases](https://github.com/YMXKNebula/DailyToolkit/releases)。同一个版本同时提供 Windows x64 安装版 EXE 和便携版 ZIP，均包含 .NET 运行环境。已在 Windows 11 x64 上测试。

安装版运行安装包即可安装或升级，在 Windows“已安装的应用”中卸载；便携版解压后运行 `DailyToolkit.exe`，更新前先退出软件，再替换程序文件。笔记和个人设置保存在用户数据目录，升级和卸载都保留这些数据。软件没有自动检查或下载更新的功能。两种包的使用和迁移步骤见 [安装说明](docs/INSTALLATION.md)。2026-10-09 重打包仍使用 0.7.9 版号，包含捕获启动和资源释放修复。

## 屏幕局部放大

默认快捷键为 `Ctrl + Shift + F8`，在后台也能使用。可以按一次开启、再按一次关闭，也可以设置为按住时开启、松开时关闭。

- 倍率为 1.00–16.00×，每步 0.25×；可用输入框、滑块或滚轮调整。
- 固定模式允许点击下方窗口；可移动模式支持拖动、中心吸附和跨屏接力。
- 尺寸可自定义，也可按屏幕比例选择预设，支持 1:1、16:9、4:3、21:9 等宽高比。
- 画质可选性能、清晰、质量、像素。清晰与质量固定使用 100% 清晰度；性能优先响应，质量的 GPU 开销更高。
- 框体颜色可以更换，照片预览与实际放大框使用同一套画面处理，位置各自独立。

放大不能恢复原画面没有的细节，实际帧率受系统捕获、显示器和显卡影响。详细设置及跨屏规则见 [使用说明](docs/SCREEN_LENS.md)。

> 用于带有反作弊的多人竞技游戏时，可能导致封号。请谨慎使用，后果自负。

## 浮笺

`Ctrl + Alt + N` 显示或隐藏笔记；`Ctrl + Alt + Shift + N` 切换已显示笔记的聚焦状态。两个快捷键可以分别修改或清空。

聚焦后可以编辑，外框与正文边框显示所选颜色，默认完全不透明；再次按聚焦快捷键或 Esc 会取消聚焦并尝试返回此前窗口，笔记仍留在屏幕上。失焦时鼠标操作穿透到下方程序；位置设置中的“点击浮笺聚焦”默认关闭，开启后只接收左键来聚焦，右键、中键和滚轮仍穿透。编辑时双击正文可以选词。正文支持多行输入、复制粘贴、撤销和中文输入法。

固定模式保留位置；聚焦时，可移动模式从空白顶部直接拖动，支持跨显示器移动。左下角按钮隐藏笔记、右下角调整大小，固定模式也能缩放；两个控件只显示图形标记，没有底色或外边框，手动调整可在尺寸设置旁关闭。宽高使用整数。失焦时隐藏边框、滚动条及操作按钮，并停止拖动、缩放和选词；滚动条透明度与背景一致。

失焦时正文显示区域的上下留边与左右相同，多显示原有内容，空余部分留白；文字位置、字号和行距保持原样，聚焦后恢复编辑范围。聚焦时，正文在有内容被遮挡的上下边缘静态渐隐，失焦后取消渐隐。

提供十套背景、文字及聚焦边框配色，颜色也能点选或打开颜色对话框选择。透明度、系统字体、字号、粗细、圆角和置顶可以单独设置，外观区域内的预览随调整更新。输入停止约 400 毫秒后自动保存，隐藏和正常退出会保存最后的编辑。数据位于 `%LOCALAPPDATA%/DailyToolkit/Notes/`，更新软件不会清空笔记。

详细操作、数据恢复及检查步骤见 [浮笺说明](docs/FLOATING_NOTES.md)。

## 界面和设置

左侧列出工具，可以拖动排序或右键上移、下移。红绿滑动开关控制工具是否可用：停用会关闭工具并撤销快捷键，重新启用不会自动开启放大框。点击工具配置标题左侧的星标加入收藏，左下角星形打开收藏夹，齿轮打开设置。

设置提供主题配色、动画速度、后台运行和开机自启选项。预设主题点选后生效；自定义色号先在预览中显示，点击“保存配色”后应用。关于页显示版本、作者、许可证和项目主页。

关闭窗口或最小化时可以留在托盘，放大框、浮笺和快捷键继续运行；从托盘菜单退出才会完全关闭。重复打开程序会恢复已有窗口。`--show` 可显示首次启动窗口，`--exit` 可退出后台实例。

普通自启使用当前用户的启动项，管理员自启使用当前用户的计划任务，不保存密码。移动便携文件夹前，请先关闭自启，在新位置重新启用。管理员自启和静默启动可以同时使用。

## 电脑信息和本地数据

“电脑详情”显示日期、天气、网络、电源、硬件配置及安装记录，支持搜索、复制摘要和导出 JSON。软件安装记录可能漏掉便携软件和部分商店应用。

信息从 Windows 读取，检测结果不上传。天气读取本机缓存或任务栏文字，不请求天气服务；网络状态和流量来自 Windows，不进行联网测速。导出的报告可能含硬件配置、软件名称和本机状态，分享前请先查看。

个人设置、工具顺序和收藏保存在 `%LOCALAPPDATA%/DailyToolkit/`，兼容读取旧版 DailyUSE 设置。主窗口进入后台后会暂停电脑信息刷新和照片预览，实际放大框的捕获、画质与快捷键照常工作。

## 从源码构建

需要 Windows 和 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)。

```powershell
.\scripts\build.ps1
.\src\DailyToolkit.Desktop\bin\Release\net10.0-windows10.0.26100.0\DailyToolkit.exe
```

打包便携版：

```powershell
.\scripts\publish.ps1
```

输出为 `artifacts/DailyToolkit-<版本>-win-x64/` 和 `DailyToolkit-<版本>-win-x64-portable.zip`。首次打包会下载 .NET 运行时。

打包安装版：

```powershell
.\scripts\package-installer.ps1
```

先从 [Inno Setup 官方网站](https://jrsoftware.org/isdl.php)安装编译器，支持 6.5 及更新版本；不在项目脚本中下载和执行安装工具。也可以用 `-Compiler` 指定本地 `ISCC.exe`。输出为 `DailyToolkit-<版本>-win-x64-setup.exe`，两种包共用程序文件，摘要写入 `SHA256SUMS.txt`。GitHub Actions 使用运行环境已有的编译器，同时构建、检查并打包这两个版本。
