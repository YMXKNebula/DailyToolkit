# DailyToolkit

Windows 桌面工具集，提供放大镜、浮笺和电脑信息查看。

[下载最新版](https://github.com/YMXKNebula/DailyToolkit/releases/latest) · [安装与更新](docs/INSTALLATION.md) · [0.7.9 更新说明](docs/RELEASE_079.md)

## 下载和运行

| 下载文件 | 使用方式 |
| --- | --- |
| 安装版 EXE | 运行安装包，安装后从开始菜单打开；可在 Windows“已安装的应用”中卸载 |
| 便携版 ZIP | 解压后运行 `DailyToolkit.exe`，适合自行管理程序文件夹 |

下载包包含运行环境，无需另外安装 .NET。目前提供 Windows x64 版本，已在 Windows 11 x64 上测试。

## 放大镜

放大屏幕上的一块区域，适合查看文字、图片和画面细节。默认按 `Ctrl + Shift + F8` 开启或关闭，在其他程序前台也可以使用。

可以自行设置：

- **操作方式**：修改快捷键，选择按一次切换或按住时放大，开启或关闭滚轮调节。
- **放大倍率**：1.00–16.00×，每步 0.25×，支持滑块、输入框和滚轮。
- **画质**：性能优先响应；清晰适合文字和桌面；质量更注重纹理与边缘；像素保留像素边界。
- **尺寸与比例**：自定义宽高，或选择小、中、大预设；宽高比可选跟随屏幕、1:1、16:9、4:3、21:9。
- **位置**：固定模式可点击下方窗口；可移动模式支持拖动、中心吸附和跨屏移动。
- **边框与帧率**：点选或自选边框颜色，选择跟随画面或帧率上限。

配置旁的照片预览可以试调倍率、位置和外观。详细操作见 [放大镜说明](docs/SCREEN_LENS.md)。

> 用于带有反作弊的多人竞技游戏时，可能导致封号。请谨慎使用，后果自负。

## 浮笺

把文本笔记留在桌面上，随时记录待办、草稿或临时内容。输入会自动保存，隐藏笔记或正常退出也会保存。

| 操作 | 默认快捷键 |
| --- | --- |
| 显示或隐藏笔记 | `Ctrl + Alt + N` |
| 切换已显示笔记的编辑状态 | `Ctrl + Alt + Shift + N` |
| 结束编辑 | `Esc` |

可以分别修改或清空两个快捷键。结束编辑后，笔记仍留在屏幕上，鼠标操作可以穿过笔记到达下方程序；需要点击笔记开始编辑时，可开启“点击浮笺聚焦”。

可以自行设置：

- **位置与大小**：固定或可移动，调整整数宽高，开启或关闭右下角拖动缩放。
- **颜色**：选择十套配色，或分别选择背景、文字和编辑边框颜色。
- **透明度**：分别调整背景与文字透明度，选择编辑时是否完全不透明。
- **字体**：选择本机字体、字号和粗体，使用字体样式预设。
- **外观**：调整圆角、置顶，边调边看旁边的预览。

编辑时按住空白顶部可拖动笔记，左下角按钮用于隐藏，右下角用于调整大小。长笔记的上下遮挡边缘会渐隐，结束编辑后可多显示几行正文。固定模式也能使用缩放角。

保存、导出和恢复方法见 [浮笺说明](docs/FLOATING_NOTES.md)。

## 主题、收藏与后台运行

- 在工具配置标题左侧点亮星标，把工具加入收藏夹；左下角星形按钮打开收藏夹。
- 拖动工具列表排序，也可以右键上移、下移。红绿开关控制工具是否启用。
- 主题提供十二套预设，也可以自定义界面颜色；自定义配色预览后点击“保存配色”应用。
- 动画速度可调，也可以关闭动画。
- 可设置关闭窗口或最小化时留在托盘，使用托盘菜单重新打开或退出。
- 可设置开机自启、管理员启动和静默启动。管理员启动需要 Windows 授权，静默启动只显示托盘图标。

## 电脑详情

在设置中查看日期、天气、网络、电源、硬件和软件安装记录。支持搜索安装记录、复制摘要和导出 JSON 报告。

电脑信息从 Windows 读取，不上传检测结果。天气取自本机已有的信息，网络流量取自 Windows 统计。安装记录可能漏掉便携软件和部分商店应用，分享报告前可先检查其中的内容。

## 更新与笔记数据

在“关于”页点击“检查更新”，发现新版后点击“更新”。安装版会下载安装包并自动升级，完成后重新打开软件；便携版会下载新版 ZIP，保存位置由你选择，解压后再运行。

笔记和个人设置保存在 `%LOCALAPPDATA%\DailyToolkit\`。更新、移动程序文件夹或卸载安装版不会清空这个目录。笔记正文有 `.bak` 备份，也可以在浮笺配置中导出文本。安装、迁移自启和卸载步骤见 [安装说明](docs/INSTALLATION.md)。
