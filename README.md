# DailyToolkit

Windows 本地工具集合。各项工具独立开发，第三方依赖遵循相应许可证。

目前是 Windows 本地软件，使用 C# / .NET 10 和 WPF。日期、天气、网络和电脑信息都从 Windows 读取，检测结果不上传。

当前源码版本为 **0.7.0**，变化与验证范围见 [更新说明](docs/RELEASE_070.md)。

## 使用

左侧直接列出各个工具，没有分类页。拖动选项可以调整顺序，也可以右键上移、下移；顺序保存在本机。工具旁的总开关以绿色表示启用、红色表示停用，采用胶囊形滑动开关：启用时绿色、白色圆钮在右侧，停用时红色、圆钮在左侧；支持点击或左右拖动，白色圆钮平移与红绿底色过渡同步进行。停用会关闭工具并释放资源、取消快捷键注册；重新启用只恢复可用状态，不自动开启放大框。收藏夹使用同一开关和工具状态。

窗口和控件采用圆角。选中项通过弧形连接右侧配置区，点击其他选项时，圆形波浪从鼠标点击的位置向四周扩张，只作用于选中的选项行和右侧对应配置区，边缘使用当前主题强调色的淡渐变；默认约 220 毫秒。设置与收藏列表共用该效果。在主题配色的“切换动画”中可将速度设为 0.1–2 倍，每次调整 0.1 倍，默认 1 倍；页面、星形、齿轮和开关圆钮共用该速度。

侧栏底部的星形和齿轮等距排列。点击星形打开收藏夹，再点一次关闭，左侧列表切换为收藏的工具。展开时旋转放大并逐渐显现目标页面，退出时反向旋转缩小，逐渐变回按钮颜色。按钮与动画颜色同步，选择主题预设时一并应用，也可在颜色详细配置中单独修改。工具里的星标用于收藏或取消收藏，两处使用同一套设置和运行状态。

星形右侧的齿轮打开设置。收藏夹和设置相互替换，关闭任意一个后回到进入前的主界面，不返回另一个面板。设置的左侧目录包含主题配色、软件运行、电脑详情和关于；自启、管理员启动、静默启动与托盘选项集中在“软件运行”。切换动画的开关、速度与预览位于主题配色页。配色有浅色、深色、薄荷、海蓝、薰衣草、暖沙、玫瑰、石墨、纯白、深海、暮紫和琥珀十二套预设，按钮只显示名称，点选后立即应用并同步详细配置。“颜色详细配置”位于配色预览旁，窄窗口改为上下排列；修改界面、按钮/动画、滚动条和调节滑块的色号只更新预览，点击“保存配色”后一并应用。也可以撤销修改或恢复预览的默认配色，未保存的修改不会写入个人设置。所有自选颜色按钮采用统一的彩色轮盘。产品图标、版本、作者、许可证及项目主页集中显示在“关于”。切换起始帧保留完整旧画面，关闭 Windows 动画或启用高对比度时直接切换。

后台运行可分别设置关闭窗口或最小化时留在托盘，全局快捷键继续有效。点击 DT 托盘图标恢复窗口，右键可打开设置或退出。软件、托盘与关于页共用相连的纯 DT 字母图标，字母共用连续顶横，底线、笔画和圆角保持一致，背景为从中心向外旋转铺开的 RGB 渐变。

电脑信息首次进入“电脑详情”时读取，时钟与网络的定时刷新只在该页面位于前台时运行。窗口转入后台、隐藏或最小化后暂停预览刷新，空闲超过两秒时释放照片预览的图形资源，保留最后一张预览便于恢复。全局快捷键继续有效；正在运行的放大框保持原捕获频率与画质，不随主窗口隐藏而降帧。

启动选项默认关闭，修改后直接保存，无需点击应用按钮。管理员启动与静默启动位于开机自启下方，可同时启用。管理员自启首次启用及关闭后重新启用时请求一次 UAC 授权，后续通过当前用户的已授权任务启动整个软件；静默启动仅显示托盘。已在管理员模式下运行时，可直接修改启动设置，无需再次授权或重启软件。取消授权或保存失败时恢复原选项。单独点击“以管理员权限重启”可立即切换运行权限。

设置中的“电脑详情”显示日期、天气、网络、电源和配置。硬件详情、运行环境和已安装软件可以展开查看，支持搜索、复制配置摘要和保存 JSON 报告。

“屏幕局部放大”可以放大桌面或其他游戏的一小块画面。进入工具页面就能看到全部设置，可调整倍率、宽高、框体颜色、位置模式和帧率。颜色可以点选色块，也可以自选；预览和屏幕边框会一起更新。默认快捷键是 `Ctrl + Shift + F8`，软件在后台也能开启和关闭。

尺寸预设有小、中、大三档，按当前屏幕宽高的 20%、30%、40% 计算。宽高比可选跟随屏幕、1:1、16:9、4:3 或 21:9，所选比例会放进对应尺寸范围，跨屏后自动按目标屏幕重新计算。自定义模式仍可分别设置宽高，切回自定义时保留原值。

放大框默认固定，鼠标可以点击下面的窗口。选择“可移动”后，按住画面任意位置拖动，点击不会传到下方窗口。框碰边后仍可继续查看边缘区域；鼠标到达邻屏对称框的中心轴时才跨屏，靠近屏幕中心时保留吸附。倍率为 1.00–16.00×，每步 0.25×，滚轮调节时在框内短暂显示当前倍率。可选择性能、清晰（推荐）、高质量、像素四种画质，清晰度单独保存。荷花照片用来预览效果，预览位置与屏幕上的位置互不影响。详细用法见 [屏幕局部放大](docs/SCREEN_LENS.md)。

> 屏幕局部放大用于带有反作弊的多人竞技游戏时，可能导致封号。请谨慎使用，后果自负。

天气优先读 Windows 小组件的本机缓存，读不到时尝试任务栏天气文字。缓存由 Windows 更新，软件不请求天气服务。网络状态和流量来自 Windows，不发起联网测速。

软件安装列表来自 Windows 安装记录，可能漏掉便携软件和部分商店应用。报告包含硬件配置、软件名称和已读取的本机状态，分享前请先查看。

## 运行和构建

便携版解压后打开 `DailyToolkit.exe`，不需要另装 .NET。目前在 Windows 11 x64 上验证。

重复打开会切回正在运行的窗口，不会另外启动一份。

普通自启使用当前用户的启动项，管理员自启使用 `DailyToolkit-<用户 SID>` 任务，不保存密码。更改自启或管理员选项时更新启动注册；仅更改静默启动时只保存本地偏好。启用后需保持程序路径不变；移动前先关闭自启，在新位置重新启用。管理员任务被外部删除后需重新启用。`--show` 可强制显示首次启动窗口，`--exit` 可退出后台实例。

从源码构建需要 Windows 和 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)：

```powershell
.\scripts\build.ps1
.\src\DailyToolkit.Desktop\bin\Release\net10.0-windows10.0.26100.0\DailyToolkit.exe
```

生成便携版：

```powershell
.\scripts\publish.ps1
```

输出在 `artifacts/DailyToolkit-<版本>-win-x64/`，同目录有对应版本的 ZIP。首次打包需要下载 .NET 运行时包。仓库的 GitHub Actions 也会生成便携包。

设置保存在 `%LOCALAPPDATA%/DailyToolkit/`。仍兼容旧版 DailyUSE 的快捷键、模式和收藏，保存时写入新目录。
