# DailyToolkit

把平时用得上的小工具放到一个软件里。

项目现名 DailyToolkit。旧版的快捷键、模式和收藏继续读取，新设置保存在 `%LOCALAPPDATA%/DailyToolkit/`，配置格式不变。

这个项目主要给自己日常使用。遇到想省点事的操作，就写成一个小工具，慢慢加进来。

工具的功能自己实现，通用库按需要使用，并遵守各自的许可证。

## 进度

现在有一个 Windows 桌面框架，主程序用 C# / .NET 10 和 WPF 编写。

窗口先打开，再在后台读取系统、处理器、内存、显卡、磁盘、显示和运行环境信息。根据内存、电量和窗口大小调整检测并发及界面。检测结果只在本机使用，不上传。

首页把日期、天气、网络、电源和电脑信息放在一起。配置、运行环境和软件安装记录可以展开查看，也能搜索软件名称、复制配置摘要和保存 JSON 报告。其他日常工具会慢慢加进来，见 [开发计划](docs/PROJECT_PLAN.md)。

导航分为“首页 / 日常 / 游戏 / 收藏夹”。工具收起时只占一行，点击名称或右侧箭头展开详细设置；点亮星标后会加入收藏夹，收藏保存在本机。

左侧“游戏”页有“屏幕局部放大”，同一行显示快捷键和“按住 / 切换”模式，展开后可调整画面。软件最小化或其他窗口在前台时，同一个快捷键也能直接开启和关闭放大框，不用先手动开启。关闭会释放捕获和渲染资源，下一次按键可重新开启。框内通过显卡做高质量插值和锐化，框外保持原样。快捷键可以修改或清空，具体用法见 [屏幕局部放大](docs/SCREEN_LENS.md)。这个分区属于 DailyToolkit，与其他游戏开发项目独立。

详细设置能分别调整框的宽、高，旁边用荷花照片预览倍率、尺寸和锐化。照片随软件保存，离线也能看。位置默认“固定”，只锁住当前位置；选“可移动”后，按住放大画面拖动整个浮窗，可以放到所选屏幕的不同位置。拖动时在桌面显示屏幕中心辅助线，靠近时吸附，松手后隐藏。预览和实际浮窗的位置互不影响。详细设置最下方的“恢复默认”会回中，并恢复默认画面和固定模式，保留快捷键、按住／切换模式和收藏。鼠标放在框内时用滚轮调倍率；默认按捕获到的新帧渲染，也可设置帧率上限。

> 屏幕局部放大用于带有反作弊的多人竞技游戏时，可能导致封号。请谨慎使用，后果自负。

倍率最高 10×，倍率滑块下可开关“滚轮调节”，选择保存在本机。画面优先跟随新捕获帧，锐化复用插值采样以减轻显卡负担；放大着色器在后台提前准备，减少快捷键开启时的等待。

日期用 Windows 本机时间，网络读取 Windows 的连接状态和网卡计数器，不发起测速或连通性请求。天气优先读取 Windows 小组件保存在本机的天气缓存，显示温度、天气、地点和更新时间；没有可用缓存时再尝试读取任务栏天气文字。缓存由 Windows 更新，DailyToolkit 不请求天气服务。

## 运行和构建

已打包的版本解压后打开 `DailyToolkit.exe`，不需要另外安装 .NET。当前在 Windows 11 x64 上验证。

从源码构建需要 Windows 和 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)：

```powershell
.\scripts\build.ps1
.\src\DailyToolkit.Desktop\bin\Release\net10.0-windows10.0.26100.0\DailyToolkit.exe
```

`build.ps1` 会编译并运行检查。生成便携包：

```powershell
.\scripts\publish.ps1
```

输出位于 `artifacts/DailyToolkit-win-x64/` 和同目录的 ZIP。首次打包需要下载官方 .NET 运行时包，软件本身离线运行。GitHub Actions 也会生成便携包，见仓库的 Actions 页面。

## 增加工具

C# 工具可以直接调用公共代码。Python、Node.js 或原生可执行程序可以通过本地进程和 JSON 交换数据，不需要启动网页或服务器。接口和目录见 [框架说明](docs/FRAMEWORK.md)。

软件安装列表来自 Windows 安装记录，可能漏掉便携软件和部分商店应用。检测失败的项目会标为不可用，不阻止打开界面。保存的报告包含硬件配置、软件名称和页面读取到的本机状态，分享前请自行查看。
