# DailyToolkit

把自己常用的小工具放在一起，打开就能用。功能按需要自己写，通用库按各自许可证使用。

目前是 Windows 本地软件，使用 C# / .NET 10 和 WPF。日期、天气、网络和电脑信息都从 Windows 读取，检测结果不上传。

## 使用

左侧直接列出“电脑”和各个工具，没有分类页。拖动选项可以调整顺序，也可以右键上移、下移；顺序保存在本机。

点击左下角星形图标打开收藏夹，再点一次关闭。打开时星形旋转展开，覆盖标题栏下面的内容后显示页面；关闭时反向旋转，收回到左下角。两个方向使用同一颜色，左侧列表切换为收藏的工具。工具里的星标用于收藏或取消收藏，两处使用同一套设置和运行状态。

星形右边的齿轮打开软件设置，再点一次回到原来的工具或收藏夹。两个小图标大小一致，保留原来的样式；放大后的齿轮动画内外填成同一颜色。设置中可开关动画、选择统一的动画颜色、分别调整窗口、侧栏、文字、边框和按钮颜色，附有实时配色预览及浅色、深色预设。标题栏与窗口按钮不被动画遮盖；关闭 Windows 动画或使用高对比度时直接切换。

后台运行可分别设置关闭窗口或最小化时留在托盘，快捷键继续可用。点击 DT 托盘图标恢复窗口，右键可打开设置或真正退出。软件图标和托盘图标使用同一套 DT 组合字标：顶横相接、笔画斜切，保留小尺寸下的字母留白。

“启动”中先选择开机自启，下面是管理员启动与静默启动，点击“应用启动设置”后生效，默认均关闭。管理员自启启用时请求一次 UAC 授权；关闭后重新启用会再次请求，之后通过当前用户的已授权启动任务运行整个软件和小工具。静默启动只显示托盘，可与管理员模式同时使用。也可单独点击“立即以管理员权限重启”，这次操作按 Windows 提示授权。

“电脑”显示日期、天气、网络、电源和配置。硬件详情、运行环境和已安装软件可以展开查看，支持搜索、复制配置摘要和保存 JSON 报告。

“屏幕局部放大”可以放大桌面或其他游戏的一小块画面。进入工具页面就能看到全部设置，可调整倍率、宽高、框体颜色、位置模式和帧率。颜色可以点选色块，也可以自选；预览和屏幕边框会一起更新。默认快捷键是 `Ctrl + Shift + F8`，软件在后台也能开启和关闭。

放大框默认固定，鼠标可以点击下面的窗口。选择“可移动”后，按住画面任意位置拖动整个框，点击不会传到下方窗口；支持跨屏，靠近屏幕中心时吸附。倍率为 1–10×，可开关滚轮调节。荷花照片用来预览效果，预览位置与屏幕上的位置互不影响。详细用法见 [屏幕局部放大](docs/SCREEN_LENS.md)。

> 屏幕局部放大用于带有反作弊的多人竞技游戏时，可能导致封号。请谨慎使用，后果自负。

天气优先读 Windows 小组件的本机缓存，读不到时尝试任务栏天气文字。缓存由 Windows 更新，软件不请求天气服务。网络状态和流量来自 Windows，不发起联网测速。

软件安装列表来自 Windows 安装记录，可能漏掉便携软件和部分商店应用。报告包含硬件配置、软件名称和已读取的本机状态，分享前请先查看。

## 运行和构建

便携版解压后打开 `DailyToolkit.exe`，不需要另装 .NET。目前在 Windows 11 x64 上验证。

重复打开会切回正在运行的窗口，不会另外启动一份。

普通自启使用当前用户的启动项，管理员自启使用 `DailyToolkit-<用户 SID>` 任务，不保存密码。只有在设置里点击应用才添加或删除启动项。启用后请保持便携程序的路径不变；需要移动时先关闭自启，再在新位置重新启用。管理员任务被外部删除后需重新启用。`--show` 可强制显示首次启动的窗口，`--exit` 可关闭后台实例。

从源码构建需要 Windows 和 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)：

```powershell
.\scripts\build.ps1
.\src\DailyToolkit.Desktop\bin\Release\net10.0-windows10.0.26100.0\DailyToolkit.exe
```

生成便携版：

```powershell
.\scripts\publish.ps1
```

输出在 `artifacts/DailyToolkit-win-x64/`，同目录有 ZIP。首次打包需要下载 .NET 运行时包。仓库的 GitHub Actions 也会生成便携包。

设置保存在 `%LOCALAPPDATA%/DailyToolkit/`。仍兼容旧版 DailyUSE 的快捷键、模式和收藏，保存时写入新目录。
