# DailyUSE

一个逐步构建的开源日常工具集合：用统一入口，集成自己编写、自己使用的小工具。

## 项目定位

DailyUSE 从真实的日常需求出发，把重复、零散或不方便的操作做成易用的小工具。每个工具围绕一个明确的问题实现，再逐步整合到统一应用中。

- **自行实现**：核心工具逻辑自行设计和编写，不复制现成产品的源码，也不把其他软件打包后作为自己的工具发布。
- **按需迭代**：先把一个经常使用的小工具做好，再扩展更多模块。
- **模块清晰**：各工具保持清晰边界，方便独立维护、验证和扩展。
- **操作可控**：处理用户文件和数据时，优先提供清楚的操作说明；涉及批量修改时，设计预览和恢复机制。
- **尊重开源依赖**：可以使用通用基础库，但需要遵守许可证并保留必要的归属说明。

## 当前状态

项目处于初始化阶段，尚未实现工具功能，也没有可下载的应用版本。

第一个工具、目标平台和技术栈将在确认具体需求后确定，见 [项目规划](docs/PROJECT_PLAN.md)。
